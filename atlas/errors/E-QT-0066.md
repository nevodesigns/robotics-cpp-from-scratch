## Symptom

A test of a QML interface passes while the interface is broken: a handler throws a ReferenceError, and the only trace is a line on a terminal.

## Cause

A runtime error in QML is printed as a warning and the object carries on. Nothing in the test is told. Measured: `Component.onCompleted: nothingCalledThis.value` loaded, and **1** warning was printed: `...throws.qml:2: ReferenceError: nothingCalledThis is not defined`.

## Fix

Keep the messages for the length of the test, and assert on them:

```cpp
rc::qt::MessageCapture capture;
load(engine, url);
RC_CHECK_EQ(capture.count(QtWarningMsg), 0u);
```
