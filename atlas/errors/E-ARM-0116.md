## Symptom

Two estimates of the same volume disagree, or a small difference between two robots changes sign.

## Cause

The error shrinks only as the square root of the number of points: 40000 points gave about 0.4 percent for the SCARA.

## Fix

Report the standard error with the volume, and use enough points that it is well below the differences being claimed.

```cpp
workspace_volume(test, box, n, seed, &se);
```
