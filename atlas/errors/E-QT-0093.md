## Symptom

A suite of interface tests passes while the interface is broken: a handler throws, a binding loops, a name is undefined, and the only trace is a line on a terminal that nobody reads.

## Cause

QML reports most mistakes as warnings and loads on. A test that asks only whether the file loaded sees none of them. Measured through the harness: a syntax error, an unknown type, an unknown property and a missing required property were load failures, and a throwing handler, a binding to an undefined name, a binding loop and a `console.warn` were warnings: **8** of 8 reported.

## Fix

Load through one object that keeps what Qt prints and asks every step for its failures:

```cpp
rc::qt::QmlHarness ui(engine);
ui.load(url);
RC_CHECK(ui.ok());
```
