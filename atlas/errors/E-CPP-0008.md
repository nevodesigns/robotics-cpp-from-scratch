title: Returning a reference to a local variable

match: address of stack memory associated with local variable

## Symptom

The compiler warns about returning a reference or address of a local. At runtime
the returned value is garbage, or correct at first and wrong later.

## Cause

Local variables are destroyed when the function returns. A reference or pointer
to one is left pointing at memory that has been reused for something else. Reading
it is undefined behaviour, and it often appears to work for a while.

## Fix

Return by value. Copying is cheap for small types, and for larger ones the
compiler usually elides the copy entirely. Return a reference only to something
that outlives the call, such as a member of an object the caller owns.
