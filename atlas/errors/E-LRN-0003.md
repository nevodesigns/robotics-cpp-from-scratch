## Symptom

The learner's test error is a little better than its error on new data, and the difference changes when the test set changes.

## Cause

The inputs were scaled with a mean and spread taken from all the data, test part included, and then split. The scale is part of the learned policy, so the test part has helped train it: a small leak, in the learner's favour. Here the spreads of the training part were 0.174 m and 0.108 rad; the whole set gives slightly different ones.

A second fault often comes with it: an input with no spread in the data, divided by zero.

## Fix

Split first, fit the scale on the training part, apply that scale everywhere, and keep it with the policy.

```cpp
rc::learn::split_by_episode(data, 5, train, test);
const rc::learn::Normaliser scale = rc::learn::fit_normaliser(train);
```

Ship the scale with the weights: a policy given inputs scaled another way is a different policy.
