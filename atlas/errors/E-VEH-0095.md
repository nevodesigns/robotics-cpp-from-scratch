## Symptom

The sampling controller follows the path into an obstacle that lies on it.

## Cause

It was given no grid, so its score had no cost for cells: 15 poses fell in blocked cells.

## Fix

Pass the cost grid to the controller so blocked cells are in the score of every rollout. With the grid, 0 poses were in blocked cells.

```cpp
const rc::drive::Command c = rc::drive::mppi_control(model, cfg, pose, path, idx, &grid, state);
```
