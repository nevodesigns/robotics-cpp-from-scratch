id: E-BUS-0010
title: Every heartbeat treated as news
match: a participant that announces itself appears once, and its repeats are heartbeats and not news
match: a participant that goes quiet for longer than its lease is gone, and said so exactly once
platforms: linux, windows
teaches: 17-04-who-is-out-there
---

## Symptom

The node graph is redrawn, a subscriber is rebuilt or a log fills with 'appeared' every second, because the same node keeps announcing itself.

## Cause

An announcement from a node already alive is a heartbeat: it extends the lease and says nothing. A new name gave one appeared event, repeated announcements gave none, and a death gave one gone event, not repeated ten seconds later.

## Fix

Report only changes of state.

```cpp
if (!e.known) queue(DiscoveryEvent::Kind::appeared, name);
```
