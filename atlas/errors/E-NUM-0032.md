## Symptom

A "better" step that uses the heading at the end of the step instead of the start is no better: it runs the other way, too short, by the same amount.

## Cause

The heading changes during the step. The start is too early and the end is too late, by equal amounts in opposite directions, and the heading halfway is right for both.

Measured on the same quarter circle, the miss in millimetres with the midpoint heading: **1.455, 0.364, 0.091, 0.023, 0.006, 0.001** for 10 to 320 steps. Each doubling of the steps divides the error by four, not two. It was within a
millimetre in **13** steps, against 1111.

## Fix

```cpp
const double halfway = start.theta + turn * dt / 2.0;
next.x = start.x + forward * dt * std::cos(halfway);
next.y = start.y + forward * dt * std::sin(halfway);
next.theta = start.theta + turn * dt;
```
