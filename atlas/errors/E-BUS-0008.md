id: E-BUS-0008
title: A length believed
match: a read past the end sets a flag that stays set, and gives zero, and never reads beyond the bytes
match: a string whose length claims more than there is fails the read, and does not return what lies beyond
platforms: linux, windows
teaches: 17-03-messages-as-bytes
---

## Symptom

A corrupt or hostile message makes the receiver read memory that is not part of it, or return a string that includes the next message.

## Cause

A length that came from the wire may say anything. A string whose length said 500 with two bytes behind it failed the read, set the flag, and returned nothing. After a failed read the flag stays set, so a byte that happens to be left is not handed out as if the read had worked.

## Fix

Check there is enough before every read, and keep the failure.

```cpp
if (!ok_ || n > size_ - pos_) { ok_ = false; return false; }
```
