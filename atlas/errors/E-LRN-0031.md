## Symptom

After many episodes the learned policy still changes from one run of training to the next in some cells, or the values wander though the task does not change.

## Cause

Each update uses one noisy outcome and moves the value a share alpha toward it. With alpha fixed and large, the value follows the last few outcomes instead of averaging many, so in a cell where two moves are nearly as good, the greedy choice flips with the noise.

## Fix

Use a smaller alpha, or one that shrinks with the number of visits to that cell and move, and judge the policy on many test runs, not one.

```cpp
rc::learn::q_update(Q, s, m, reward, next, ended, 0.1, gamma);   // alpha small, or 1 / visits(s, m)
```

The theory that Q-learning settles on the optimum assumes alpha shrinks and every move is tried often enough; a fixed alpha trades that for following a world that changes.
