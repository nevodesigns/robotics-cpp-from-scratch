## Symptom

The simulation is clean and the release crashes on the robot, or the release boots fine and the logic is unsafe.

## Cause

A candidate that passed the gate shipped in a release that crashed at 2 s: the gate passed, the release was deployed, the trial failed with rolled back and the robot ran 1.4.2 again.

## Fix

Keep both layers, and say what each does not do.

```cpp
const ShipResult s = ship_rover(robot, candidate, release, false);
```
