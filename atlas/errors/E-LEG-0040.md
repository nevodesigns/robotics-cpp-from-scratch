## Symptom

The acceleration limits come out backwards: the robot is allowed to brake hard where it tips and is held back where it is safe.

## Cause

The zero moment point was put ahead of the centre of mass for a forward acceleration. To speed up, the ground must push from behind, so the point is behind: centre of mass minus h over g times the acceleration.

## Fix

Write the sign down once in a function and test it with a known case: 3 m/s2 forward at 0.27 m puts the point 83 mm behind.

```cpp
inline void zmp_from_com(const double com[2], double h, const double a[2], double out[2]) {
  out[0] = com[0] - h / 9.81 * a[0];   // behind for a forward acceleration
  out[1] = com[1] - h / 9.81 * a[1];
}
```
