## Symptom

For one cycle in ten the robot's position is zero, and the control loop commands a lurch back to where it never was.

## Cause

A reading that did not arrive has no value. A dropout chance of 0.1 lost 2052 of 20000 readings (0.103), each marked invalid and carrying the last good value, and the model's count agreed with the marks. A loop that treats a missing reading as zero has read a position of zero.

## Fix

Mark a lost reading and hold the last good value.

```cpp
r.value = last_good_;
r.valid = false;
```
