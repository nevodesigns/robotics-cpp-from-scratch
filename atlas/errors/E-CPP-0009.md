## Symptom

Sorting or writing through a std::span of const elements fails to compile, often
with a long template error mentioning read only or discarded qualifiers.

## Cause

A span of const elements is a read only view of somebody else's data. Sorting it
would reorder the caller's array, which is exactly what the const is there to
prevent.

## Fix

Copy the elements into a local std::vector and sort that. If the caller really
does want their data reordered, take a mutable span or a reference to the
container, and name the function so the side effect is obvious.
