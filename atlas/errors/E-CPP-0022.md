id: E-CPP-0022
title: A switch that does not handle every enumerator
match: enumeration value .* not handled in switch
match: -Wswitch
platforms: linux, windows
teaches: 01-06-enums-and-states
---

## Symptom

A warning naming an enumerator not handled in a switch. Or, worse, no warning at
all and a new state silently taking the fallback branch everywhere.

## Cause

A value was added to the enum and some switch was not updated. The compiler can
find every one of those for you, but only while the switch has no default label.
Adding default tells it that every unlisted value is intentional, and the warning
never appears again.

## Fix

List every enumerator and put the fallback after the switch rather than inside
it:

```cpp
switch (state) {
  case DriveState::Idle:     return "idle";
  case DriveState::Driving:  return "driving";
  case DriveState::Stopping: return "stopping";
  case DriveState::Faulted:  return "faulted";
}
return "unknown";
```

The fallback still catches a value cast in from outside, and the compiler still
checks the enumerators. Build with warnings enabled, which this repository does,
so adding a state produces a list of every place that has to change.
