## Symptom

A count of live delegates is negative, or a budget test passes because the count was low for the wrong reason.

## Cause

A `gone` that is reported for a delegate whose `created` was not seen, for instance one made before the counter was connected, takes the count below zero. Measured: with the guard, **2** such reports were counted as unmatched and alive stayed at **0**.

## Fix

Count the report that has nothing to match, and do not subtract it:

```cpp
if (alive_ == 0) { ++unmatched_; return; }
--alive_;
```
