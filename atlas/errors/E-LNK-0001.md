## Symptom

The code compiles cleanly and then fails at the end of the build, reporting an
undefined reference to a function that plainly exists in your header.

## Cause

The declaration promised the function exists. No definition was ever supplied, or
the definition has a slightly different signature, so the linker treats it as an
unrelated function. A different parameter type or a missing const is enough.

## Fix

Check that the function has a body in a .cpp file that is part of the build.
Compare the signature character by character against the declaration, including
const and reference markers. If the body lives in a file the target does not
compile, add that file to the target.
