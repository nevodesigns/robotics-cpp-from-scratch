## Symptom

The base drives off with the arm still out, because a plan or a bug skipped the step that tucks it.

## Cause

The state machine was trusted to always tuck before driving. A plan that skipped the stow step drove with the arm out for 15 ticks.

## Fix

Pass every command through a separate interlock: the base may drive only with the arm tucked, and the arm may go out only with the base stopped. The same faulty plan then ended in a timeout with 0 unsafe ticks.

```cpp
bool blocked = false;
const rc::mobile::MissionCmd safe = rc::mobile::guard(want, in, &blocked);
```

The interlock is two lines applied to whatever the state machine says, which is why it holds when the state machine is wrong.
