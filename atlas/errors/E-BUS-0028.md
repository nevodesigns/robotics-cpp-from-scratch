## Symptom

A goal reported as succeeded is later reported as executing, or one that never started reports success.

## Cause

A goal is a state machine with a legal order: accepted, executing, then succeeded, aborted, or canceling and canceled. A move out of order is refused and the goal stays where it was. Succeeded, canceled and aborted goals had every method called on them afterwards and none changed.

## Fix

Check the current state in every transition.

```cpp
bool move(GoalState from, GoalState to) { if (state_ != from) return false; state_ = to; return true; }
```
