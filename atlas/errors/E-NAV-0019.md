title: A plan that outlived the map it was made from

## Symptom

The robot drives confidently into something that was not there when it set off:
a pallet put down after the route was planned, a door that closed, a person who
stopped in the aisle.

The obstacle is in the map. The sensors saw it, the grid was updated, the
display shows it. The robot drives into it anyway.

## Cause

A plan is a photograph of a map. It is a list of cells, and it holds no
reference to the map it came from, so it cannot tell that the map has changed
underneath it.

Measured: a route planned across a room, then a pallet set down where the route
crosses a gap. Five cells of the plan are now inside an obstacle, and the plan
still says to drive through them. Replanning on the updated map found a route
0.5 m longer that avoids it entirely.

Nothing in the system was wrong except that nobody asked the question again.

## Fix

Check the current plan against the current map every tick, and replan when the
check fails.

```cpp
for (const auto& cell : plan.cells)
  if (map.classify(cell.x, cell.y) == rc::nav::Cell::occupied) { replan(); break; }
```

Checking is far cheaper than planning: it is a walk down a few hundred cells
against a search that expands tens of thousands, which is what makes it
affordable at the control rate while replanning is not.

Three things that go with it.

**Check the part you have not driven yet**, not the whole route. The cells
behind the robot are history and an obstacle there is not a reason to replan.

**Check the inflated map**, not the raw one, or the check passes right up until
the robot's edge touches something.

**Have an answer for no route.** The replan may fail, and stopping is a valid
outcome that something has to be prepared to hear. A robot that keeps driving
the old plan because the new one came back empty is worse than one that stops.

Replanning on a timer as well as on the check is worth it where the map improves
rather than merely degrading: a route planned through unknown ground gets better
as the ground is seen, and nothing about that trips an obstacle check.
