## Symptom

A transcript test fails with 'sessions differ' and nobody can tell where, or with forty differences after the first that are all the same mistake.

## Cause

Compare message by message and report the first difference with its place. A byte changed in message 3 was content at message 3 byte 6; a message the other way was direction at 2; one more message was extra from 6; two fewer was missing from 4. New firmware adding a byte was length at message 1, offset 8; a reading one too high on request 3 was content at message 5, byte 6. A changed reading was one line of text different.

## Fix

Stop at the first difference.

```cpp
d.kind = Difference::Kind::content;
d.message = i;
d.offset = k;
return d;
```
