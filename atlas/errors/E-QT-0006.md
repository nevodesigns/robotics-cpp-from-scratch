## Symptom

A custom widget shows only its background, or nothing at all. Qt may warn that
QPainter::begin failed, or that paintEngine should no longer be called.

## Cause

Almost always one of three things. Painting was attempted outside paintEvent,
which is not supported for a widget. A QPainter was constructed on a widget that
is not the one currently being painted. Or paintEvent was spelled differently
from the virtual function it was meant to override, so it is a new function that
Qt never calls.

## Fix

Do all drawing inside paintEvent, construct the painter on this, and mark the
override so the compiler checks the signature for you:

```cpp
void paintEvent(QPaintEvent*) override {
  QPainter painter(this);
  painter.fillRect(rect(), background_);
}
```

Adding override to every intended override turns a silent do nothing bug into a
compile error, which is worth doing everywhere rather than only here. To trigger
a repaint from elsewhere, call update() rather than trying to paint.
