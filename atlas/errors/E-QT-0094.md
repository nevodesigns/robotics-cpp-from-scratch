title: A refused read or write that a test did not look at
match: a read, a write or an expression that is refused is a failure, and one that worked is not
match: expected probes
platforms: linux, windows
teaches: 11-12-the-interface-that-reports-itself

## Symptom

A test sets a property from C++ and asserts on the result. The property name had a typo. The set returned a result that said no, and the test did not read it.

## Cause

A probe returns a result, and a result that nobody checks is not a failure unless something records it. Measured: a typo read, a typo write and a bad expression through the harness were **3** failures of kind `probe`, naming `cuont` and `widht`.

## Fix

Make the harness the place the result goes, so that a refusal is recorded whether or not the caller looks:

```cpp
if (!result.ok) own_.push_back(Failure{"probe", result.error});
```
