id: E-IO-0027
title: The buffer filled while nobody was reading
match: a reader that comes round slower than the buffer fills loses bytes, at the predicted rate
match: a byte on the wire is ten bits, so 115200 baud carries 11520 bytes a second
platforms: linux, windows
teaches: 08-08-a-device-faster-than-you-read
---

## Symptom

Messages go missing in bursts, and only when the program was busy: during a file
save, a redraw, a log flush, a garbage collection in a language that has one. The
bursts line up with the pauses. The cable is fine, the checksum counters are
zero, and a faster computer makes it rarer but not gone.

## Cause

A serial driver holds what has arrived in a buffer of fixed size, typically 4096
bytes. A device keeps sending whether anyone is reading or not. When the buffer is
full, **new** bytes are dropped, and no error is raised anywhere: the driver
counts an overrun at best, and the program is never told.

How long the reader may stop depends on the rate, and the rate is easy to get
wrong by a quarter, because a byte on the wire is **ten** bits (a start bit, eight
data bits and a stop bit), not eight:

| | |
|---|---|
| 115200 baud, bytes a second | 11520, not 14400 |
| 4096 bytes at that rate | 0.356 s from empty to full |
| a device sending 500 frames of 11 bytes a second | 5500 bytes a second, 0.745 s |

Measured, a reader that came round every 700 ms lost nothing. At 800 ms it lost
726 of 10100 frames, against 691 predicted. At 2000 ms it lost 6290 against 6276.
The prediction is the stall past the budget, times the rate, times the number of
stalls.

## Fix

Work out the budget and keep every read under it.

```cpp
const double budget = stall_budget(4096, 500.0 * 11.0);   // 0.745 s
```

Then look for what can hold the reading loop longer than the budget and move it
off the thread that reads: logging, drawing, disk. Lesson 08-10 puts the reading on a thread of its
own so that nothing else can hold it. Count what is lost with a sequence number
rather than inferring it, which is the first half of this lesson.
