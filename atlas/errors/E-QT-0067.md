title: A message handler left installed after its scope
match: the old handler is put back when the scope ends, and a nested scope hands back to the one around it
match: expected outer.size() to equal 2u
platforms: linux, windows
teaches: 11-03-the-warning-nobody-read

## Symptom

A test run crashes or prints nothing after one test, or a later test sees messages that an earlier one provoked.

## Cause

`qInstallMessageHandler` is global and returns the handler it replaced. A scope that does not reinstall it leaves a pointer to a dead object. Measured: nested scopes kept **2** and **2** messages in the right places, and the old handler was back, and saw the next message, when they ended.

## Fix

Remember the old one and put it back in the destructor:

```cpp
~MessageCapture() { qInstallMessageHandler(previous_); current().store(outer_); }
```
