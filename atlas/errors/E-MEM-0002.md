title: Deleting an object twice

## Symptom

The program crashes on exit or when a window closes, reporting a double free or
heap corruption.

## Cause

Two owners believe they are responsible for the same object. In Qt this usually
means a QObject created on the stack was also given a parent, so the parent
deletes it and then the stack unwinds and deletes it again.

## Fix

Pick one owner. Objects created with new and given a parent are owned by that
parent. Objects on the stack must have no parent. Outside Qt, use
std::unique_ptr so ownership is expressed in the type rather than in a comment.
