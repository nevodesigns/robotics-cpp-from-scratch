## Symptom

A tool is given a bad third number. It has already drawn a picture, and the picture is followed by an error message. The picture looks like a result. A script that reads the output uses it.

## Cause

The inputs were checked as they were needed and not before. Output written before the problem was found cannot be taken back.

Typing `fast` for the right speed gave status **2** and **0 characters** on the standard output. The error went to the other stream, so a script that reads the output has nothing to misread.

## Fix

Read and check everything first, then act:

```cpp
for (int i = 0; i < 3; ++i) {
  const Asked asked = ask(in, low[i], high[i], 1);
  if (!asked.entry.ok) { err << /* which value, what was wrong */; return status_for_misuse(); }
  value[i] = asked.entry.value;
}
// only now: drive and draw
```
