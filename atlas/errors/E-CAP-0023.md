## Symptom

The robot's tests are green after somebody removes the range limiter, because every test is of the robot doing its task.

## Cause

With the limiter and supervisor taken out S1 and S3 still passed and S2, S4 and S5 failed; the summary named failing: G1, G2, G4, G8 and suite_green was false.

## Fix

Write the scenario that makes the safety layer necessary.

```cpp
scenario.passes = [](const DeliveryResult& r) { return r.bumps == 0; };
```
