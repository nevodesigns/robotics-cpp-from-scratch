## Symptom

You added the Q_OBJECT macro, rebuilt, and got exactly the same linker error.

## Cause

Which files are handed to moc is decided when the build system configures, not
when it compiles. Adding the macro after that decision has no effect until the
build system looks again.

## Fix

Reconfigure the build: cmake -S . -B build/default
If that does not clear it, delete the build directory and configure from scratch.
Confirm afterwards that a file named moc_yourheader.cpp appears somewhere under
the build directory, which is proof that moc ran.
