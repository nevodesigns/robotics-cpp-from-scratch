## Symptom

A bug in a gain, a sign or a sensor makes the controller ask for an enormous torque, and the joint slams, a gear strips, or the robot flips. The controller had limits, but somewhere upstream.

## Cause

No limit was applied at the very last stage, between the controller and the motor driver. Limits inside the controller are part of what can be wrong. The safety layer clips every joint's command to the peak the motor may give, in either direction: a command of 40 N m was cut to 20.

## Fix

Clip at the last stage, after everything else, and do it in code that does not depend on the controller being right.

```cpp
for (int j = 0; j < 12; ++j)
  tau_out[j] = rc::legged::apply_scale(rc::legged::limit_torque(tau_cmd[j], 20.0), safety);
```

A clip stops the worst outcome. It does not make a wrong command right, so log every time it bites.
