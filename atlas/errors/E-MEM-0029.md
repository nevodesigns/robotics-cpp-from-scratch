## Symptom

A program that opens two ports and reads from them works. After running for a day the operating system says too many files are open, or a device is busy and nobody holds it. It happens
only after a failure, and the program does not crash.

## Cause

The open and the close are a pair and the code between them has more than one way out. The first device was opened, the second could not be, and the early return skips the close of the first.

Measured: **100** attempts where the second device could not be opened. Raw handles left **100** devices open, and the owner left **0**.

## Fix

Own the handle from the line it was opened on, so every way out closes it:

```cpp
DevicePtr first = open_checked(first_id);
if (!first) return false;
DevicePtr second = open_checked(second_id);
if (!second) return false;   // first closes itself here
```
