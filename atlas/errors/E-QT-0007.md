## Symptom

qt6-base-dev is installed, qmake6 reports a version, and CMake still says it
could not find Qt6 with the Widgets component. Just above it, often overlooked,
sits a line saying it could not find OpenGL.

## Cause

Qt6 Widgets depends on Qt6 Gui, and Qt6 Gui's CMake package requires the OpenGL
development headers. On Ubuntu 22.04 the qt6-base-dev package does not pull them
in, so the Qt package itself fails to resolve and CMake reports the component as
missing rather than reporting the real cause.

The OpenGL line is the actual error. The Qt line is the consequence.

## Fix

```
sudo apt install libgl1-mesa-dev
```

Then delete the build directory and configure again, because the failed search
is cached. Ubuntu 24.04 usually pulls the headers in through another dependency,
which is why this appears on one release and not the other and looks like a
mystery until you read the first error rather than the last.
