id: E-BUS-0035
title: A change of several settings applied halfway
match: several settings changed together are all applied or none, even when the last is the bad one
platforms: linux, windows
teaches: 17-12-settings-that-change-while-running
---

## Symptom

A retune that was refused leaves the controller with a new proportional gain and the old integral gain, and it oscillates.

## Cause

A request that changes several settings is checked against a copy and applied only when every part passes. Three changes with the last the wrong type were refused with channels: wrong type, and kp was still 2.0 and enabled still true; the same three, correctly typed, were all applied and recorded.

## Fix

Check on a copy, then apply.

```cpp
std::map<std::string, Value> proposed = values_;
```
