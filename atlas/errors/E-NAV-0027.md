id: E-NAV-0027
title: A shortcut through cells nobody has seen
match: a line over free cells is clear, and one that touches a wall or an unseen cell is not
match: a planned path is shortened to a few corners, and every piece of it is clear
match: shortening never makes a path longer, never loses its ends, and leaves a path that is already straight alone
platforms: linux, windows
teaches: 16-10-fewer-corners-same-room
---

## Symptom

The shortened path is much straighter and runs through an area the map says nothing about, or off the edge of it.

## Cause

Only a free cell has been seen to be passable. An unknown cell might be a wall, and a cell outside the grid is not on the map at all. The clear line test treats both as not free. With it, a planned path of 72 points became 8 and each piece checked clear by an independent sampler, and across 16 paths none got longer and none lost an end.

## Fix

Count only free cells as clear.

```cpp
return grid.inside(x, y) && grid.classify(x, y) == Cell::free;
```
