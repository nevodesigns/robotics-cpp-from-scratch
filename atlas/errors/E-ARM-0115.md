## Symptom

A point inside the robot's quoted reach cannot be reached the way the task needs it.

## Cause

The reach was quoted without its orientation. Whether a point can be reached depends on how the tool is to point: the yardstick of 32-05 asks for the tool level or pointing down, and a tilted tool reaches a different, usually smaller, volume.

## Fix

State the orientation with every reach figure, and ask the reach question for the task's own orientation.

```cpp
const bool ok = rc::arm::tool_down_reachable(table, x, y, z, tool);   // pointing down; ask again for a tilted tool
```
