## Symptom

```text
solution.hpp:42:7: error: 'milivolts' was not declared in this scope;
                          did you mean 'millivolts'?
   42 |   if (milivolts <= empty_mv) return 0;
      |       ^~~~~~~~~
      |       millivolts
```

Or the same message with no suggestion, for a name that looks obviously correct.

## Cause

The compiler reached a name it has never been told about. Four reasons, in
roughly the order they occur:

**A spelling.** One letter different is a different name, and the compiler has
no way to know which was meant. It will often guess, and the guess is under the
error, prefixed with `did you mean`.

**Used before it was declared.** A C++ file is read from the top, once. A
function called on line 10 and defined on line 40 does not exist yet at line 10.
Either move the definition up or put a declaration above the use, which is what
headers are for and what lesson 00-02 is about.

**Out of scope.** A name declared inside a pair of braces stops existing at the
closing brace. A variable declared inside an `if` is not available after it.

**A missing include.** Then the name is usually qualified, and the message says
it is not a member of `std` instead. See `E-CPP-0025`.

## Fix

Read the suggestion first. When the compiler prints `did you mean`, it is right
more often than it is wrong, and checking costs one glance.

When there is no suggestion, the question is which of the four it is, and the
fastest way to tell is where the name is supposed to come from:

- Declared in this file, further down: move it up, or declare it above.
- Declared in another file: include that file's header.
- Declared in a block that has ended: move the declaration out to the scope
  that needs it.
- Never declared anywhere: this is the real one, and it is usually a spelling.

One shape worth recognising, because it sends people looking in the wrong place.
A single undeclared name produces an error at every place it is used, and then
more errors for every variable built out of it. Six errors of this shape are
routinely one typo. Fix the first, rebuild, and see what is left. See
`E-CPP-0026`.
