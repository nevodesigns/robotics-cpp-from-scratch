title: A retry that goes on after stop
match: stop ends the retries for good, even when the server comes back
match: expected client.delays
platforms: linux, windows
teaches: 12-01-the-link-that-dropped
---

## Symptom

A station that has been closed reconnects to the robot, or a test that stopped a client sees a connection later, from a timer that was still waiting.

## Cause

A single shot timer that has been started fires whether or not anyone still wants it. Stopping has to end the timer and the socket and say that no more are wanted. Measured: after `stop()` and 200 ms with the server back, there were no more waits and **0** good connections.

## Fix

End the timer and the socket, and clear the flag:

```cpp
running_ = false;
retry_.stop();
socket_.abort();
```
