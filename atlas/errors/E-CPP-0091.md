## Symptom

A new controller is written and tested directly, and it works. Plugged into the robot, which holds it as a reference to the base class, it does nothing: the output is zero. No warning, no crash.

## Cause

`double output(double error)` and `double output(double error) const` are different functions. A derived class that leaves off the `const` the base has does not replace the base version, it adds another, and a call through the base type runs the base one.

Measured: gain 5 and error 2, called on the `Forgetful` itself: **10**. Through a reference to the base: **0**. The same gain written with `override` gave 10 both ways.

## Fix

Put `override` on every function that is meant to replace one:

```cpp
double output(double error) const override { return gain_ * error; }
```

The lesson's `checks/` snippet leaves the const off with `override` and the build is expected to fail, which it does: `marked 'override', but does not override`.
