id: E-CPP-0065
title: No matching constructor, because declaring one removed the default
match: (no matching function for call to .*::.*\(\)|no matching constructor for initialization|no appropriate default constructor)
platforms: linux, windows
teaches: 02-11-how-an-object-starts
---

## Symptom

A class that compiled yesterday stops compiling where someone writes a plain
declaration of it:

```
error: no matching function for call to 'Channel::Channel()'          (gcc)
error: no matching constructor for initialization of 'Channel'         (clang)
error C2512: 'Channel': no appropriate default constructor available   (MSVC)
```

```cpp
Channel c;
```

It also appears as a baffling error from inside a standard container, for
`std::vector<Channel> v(10)` or `std::map<int, Channel> m; m[3];`, which build
the elements blank and point at a line in the library.

## Cause

Declaring **any** constructor takes the default one away. A class with only

```cpp
Channel(std::string name);
```

has no `Channel()`, and the compiler does not write one, because the author has
plainly said how a `Channel` is made and "with no name" was not among the ways.

That is often the right design. A distance nobody measured is not zero, it is
nothing, and a default of zero would look like a reading. Measured in this
lesson: `Meters`, with one value constructor, is not default constructible, and
a line that tries is refused by gcc and clang, which `checks/` proves.

## Fix

First decide whether "has not been given a value" is a state that makes sense for
the class. If it is not, the error is correct and the fix is at the call site:
give the object its value.

If it is, ask for the default back:

```cpp
class Ramp {
 public:
  Ramp() = default;                          // ask for the one the compiler withdrew
  Ramp(double target, double step);
 private:
  double current_ = 0.0;                     // and give every member a value
  double target_  = 0.0;
  double step_    = 1.0;
};
```

Give the members their defaults where they are declared, so that every
constructor starts from them. `= default` on a class whose members have none
leaves them uninitialised, which is lesson 02-09.
