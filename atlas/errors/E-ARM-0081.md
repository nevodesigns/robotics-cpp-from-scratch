## Symptom

One move does not arrive and the machine waits for ever, and nothing says why.

## Cause

No state had a limit; with one, the machine stopped in fault 3 at tick 62.

## Fix

Give every state a time limit and a fault code that says which.

```cpp
if (m.ticks > m.timeout) { m.fault = 3; enter(m, kPickFault); }
```
