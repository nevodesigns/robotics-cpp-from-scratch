## Symptom

Given a goal that cannot be reached, the planner never returns. The program hangs on one goal and has to be killed.

## Cause

Nothing said when to stop. A sampling planner cannot prove there is no path; it can only run out of tries.

A sampling planner cannot prove there is no path; it can only fail to find one. Without a limit it never stops trying. A goal that is itself in collision is cheap to refuse before the search starts.

## Fix

Check the ends first: with a goal inside the wall the pose check refused it at once, after 0 iterations. Then give every plan a limit on iterations or time, and a result that says whether a path was found.

```cpp
rc::arm::PlanProblem p;
p.max_iter = 3000;
const rc::arm::PlanResult r = rc::arm::rrt_connect(p, start, goal);   // r.found false after the limit
```
