id: E-QT-0121
title: A shutdown that stops at the first failure, or runs twice
match: a step that fails or throws does not stop the ones after it, and the report says which
match: asking again does nothing, and a sequence with nothing added has nothing to do
platforms: linux, windows
teaches: 12-11-the-station-that-closed-badly
---

## Symptom

The robot keeps moving after the station is closed, because an earlier step threw and the one that stops it never ran. Or a close of an already closed link makes its own error on the second quit.

## Cause

An exception ends the steps after it unless something catches it, and a quit that is asked for more than once runs everything more than once. Measured: of 5 steps with 3 bad, all **5** ran and **3** were reported; three requests to quit ran the step **1** time.

## Fix

Catch around every step, record, go on, and mark the sequence done:

```cpp
try { if (!step()) report.failed.append(name); } catch (const std::exception& e) { report.failed.append(name + ": threw " + e.what()); } catch (...) { ... }
```
