title: A lifecycle publisher that speaks while inactive
match: shutdown is allowed from every state a node can be in while running, and not from finalized
match: a node only speaks while it is active, and what it is told to send at any other time is dropped and counted
platforms: linux, windows
teaches: 17-18-a-node-with-a-life-cycle
---

## Symptom

A camera node publishes frames full of zeros while it is still opening the device, or after it was told to pause.

## Cause

Only an active node should publish. Five messages over a node's life, one while unconfigured, one while inactive, two while active and one after deactivating, gave 2 sent and 3 dropped, with the dropped counted. Shutdown was legal from unconfigured, inactive and active, each giving finalized, and not from finalized.

## Fix

Gate the publish on the state and count what is dropped.

```cpp
if (state_ != LifeState::active) { ++dropped_; return false; }
```
