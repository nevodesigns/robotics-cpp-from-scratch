## Symptom

The speed profile dips to a crawl at one point, and the run takes longer for it. The path came straight from the planner.

## Cause

The curvature at a corner point of the planned path is very high, and the profile slows to suit it: the corner path took 8.6 s as it was and 8.2 s smoothed.

The speed profile slows for curvature, and a corner of a grid path has a very high curvature at one point. The profile slows almost to zero there, then speeds up again.

## Fix

Smooth the path (26-03) before profiling it, or plan with arcs (26-01).

```cpp
const auto v = rc::drive::speed_profile(rc::drive::smooth_path(path, &grid, cfg).path, lim, nullptr);
```
