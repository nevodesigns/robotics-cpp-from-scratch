match: QSettings reads a file as text, and takes abc for an integer as 0 with nothing said

## Symptom

A robot that was driven yesterday does not move today. The speed limit in the file is a typo, or the port is blank, and the station started with zero and said nothing.

## Cause

`QSettings` returns text from a file, and `toInt()` of text that is not a number is 0. `ok` says so, and most code does not ask. Measured: `abc` as the port was **0** with ok false, `no` as a bool was **true**, and with the strict conversions the port was the default **5000** and there was one note.

## Fix

Read through a conversion that refuses, and keep a note of the refusal:

```cpp
const int value = rc::qt::setting_int(settings_.value(key), &ok);
if (!ok) { problems_.append(key + ": not a whole number"); return fallback; }
```
