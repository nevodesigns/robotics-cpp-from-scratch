## Symptom

A component loads and creates nothing, with one line in the log that says a property was not initialized, or the object is made and a value that nothing set is used as zero.

## Cause

A property declared `required` has no default, and the object cannot start without it. `create()` returns null and keeps the error in the component. Measured: `Required property limit was not initialized`, and `create_with` returned null with the same text.

## Fix

Give it as an initial property, and report the errors when there is no object:

```cpp
if (!component.errors().isEmpty()) { delete object; *why = text; return nullptr; }
```
