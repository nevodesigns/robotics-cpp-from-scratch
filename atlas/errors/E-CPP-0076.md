## Symptom

A program run from a script, or with its input redirected from a file that has run out, prints "please enter a number" without stopping, thousands of lines a second, until
somebody kills it. Run by hand it works.

## Cause

`while (!got_a_number) ask();` assumes somebody is there. At the end of input every read fails, and failing is exactly what the loop answers by asking again.

End of input is not a bad answer. It is the end of all answers, and the stream says so: `in.eof()` is true.

Measured: asking an empty input up to 1000 times used **1 attempt**.

## Fix

Stop when the input is at its end, and bound the loop even so:

```cpp
for (int i = 0; i < attempts; ++i) {
  entry = read_number(in, low, high);
  if (entry.ok || in.eof()) break;
}
```
