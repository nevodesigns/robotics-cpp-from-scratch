id: E-CPP-0001
title: Expected a semicolon, reported on the wrong line
match: expected ';' before
match: error C2143.*missing ';'
platforms: linux, windows
teaches: 00-01-your-first-program

## Symptom

The compiler reports a missing semicolon, and the line it points at looks
perfectly fine. The real mistake is usually on the line above.

## Cause

C++ statements end with a semicolon. When one is missing, the compiler keeps
reading the next line as a continuation of the unfinished statement, so it only
notices something is wrong once it reaches a token that cannot possibly follow.
That token is on the next line, which is where the error is reported.

## Fix

Look at the line above the one named in the error. Add the missing semicolon
there. Remember that a struct or class definition also needs one after its
closing brace, which is the case people forget most.
