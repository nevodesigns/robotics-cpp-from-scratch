## Symptom

After smoothing, the path takes a different route from the plan, through places the planner never checked. The smoother's weights were set for a nicer looking path.

## Cause

The data weight was small and the smoothing weight large, so the smoother pulled the path far from the plan: 0.63 m, where a light smoother moved it 0.04 m.

A gradient smoother balances two pulls: toward the original points (the data weight) and toward a smooth curve (the smoothing weight). With the smoothing weight much larger, it pulls the path away from where the planner said it was free.

## Fix

Keep the data weight high enough that the deviation stays within the clearance the planner left, and check the smoothed path against the grid.

```cpp
rc::drive::SmoothConfig cfg;
cfg.data_weight = 0.5;
cfg.smooth_weight = 0.1;
```
