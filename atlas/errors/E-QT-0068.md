id: E-QT-0068
title: A message list written from two threads at once
match: messages printed on other threads are all kept
match: expected capture.size() to equal
platforms: linux, windows
teaches: 11-03-the-warning-nobody-read

## Symptom

The count of messages is a little less than it should be, or the test crashes inside a vector, only when a worker thread prints.

## Cause

Qt calls the handler on the thread that printed. A vector pushed from two threads without a lock loses elements and can corrupt itself. Measured: **8** threads printing **1000** each were **8000** kept, with the lock.

## Fix

Lock around every access:

```cpp
std::lock_guard<std::mutex> lock(capture->mutex_);
capture->messages_.push_back(m);
```
