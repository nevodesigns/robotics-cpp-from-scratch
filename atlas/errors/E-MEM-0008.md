## Symptom

An object is emptied or filled with rubbish after an assignment that should have
left it unchanged. Under a sanitizer it appears as a use after free, with the
free and the use in the same assignment operator.

## Cause

Copy assignment released what it held before reading from the source, and the
source was the same object. Everything after the release reads memory that has
just been given back.

It looks absurd written as a = a. It arrives in real code as a[i] = a[j] with
equal indices, as two references to one object, or through a container operation
that assigns an element to itself while sorting.

## Fix

Use copy and swap, which is immune by construction because the copy is made
before anything is released:

```cpp
Buffer& operator=(const Buffer& other) {
  Buffer copy(other);
  swap(copy);
  return *this;
}
```

For move assignment, where copy and swap does not apply, guard explicitly:

```cpp
if (this == &other) return *this;
```

Better still, hold a std::vector and write none of these operations at all.
