## Symptom

The test error is good, the policy is worse on new data, and the ridge that was chosen changes when the test set does.

## Cause

The ridge, like any setting of a learner, was tuned by looking at the test error. That makes the test set part of the training. A ridge of 100 took the weights from -1.044 and -1.576 to -0.592 and -0.614: a large change, which a choice on the wrong set will make for the wrong reason.

## Fix

Keep three parts: train to fit, validation to choose settings such as the ridge, test to report, and look at the test only once.

```cpp
rc::learn::split_by_episode(data, 5, rest, test);
rc::learn::split_by_episode(rest, 4, train, validation);
```

The same rule holds for the number of hidden units, the step size and when to stop training (38-04).
