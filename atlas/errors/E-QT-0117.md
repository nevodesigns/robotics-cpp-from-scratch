## Symptom

The program starts on the build machine and on a colleague machine that has the same Qt, and not on the robot. The message is from the loader, about a plugin or a library by name.

## Cause

The program was always run with the build machine around it. What it needed was found through a path variable or the build directory, and the files were never put in the folder that is shipped. Measured: with the platform plugin and the core library removed from a folder, the check reported **2** missing, by their patterns, in the order asked.

## Fix

List what must be in the folder, and check it before it is shipped:

```cpp
if (!has_match(folder, pattern)) report.missing.append(pattern);
```
