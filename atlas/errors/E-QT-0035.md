## Symptom

A configuration file fails to load and the program says "invalid configuration". The cause was a trailing comma on line 40, and finding it took half an hour.

## Cause

A parser knows exactly what went wrong and where. Throwing that away because "it failed" was enough to stop leaves the person with nothing to act on. A document that parses can also be the wrong shape: valid JSON that is an array, where an object was needed.

Measured on Qt 6.2: a trailing comma gave **"object is missing after a comma"**; a number of 1e999, too big for a double, gave **"illegal number"**; `[1,2,3]` gave **"not an object"** from the check after parsing; an empty input failed. Each left the output untouched.

## Fix

Keep the parser's own message and add the checks it does not make:

```cpp
QJsonParseError error;
const QJsonDocument doc = QJsonDocument::fromJson(text, &error);
if (error.error != QJsonParseError::NoError) { *why = error.errorString(); return false; }
if (!doc.isObject()) { *why = "not an object"; return false; }
```
