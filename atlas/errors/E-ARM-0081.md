title: A wait with no time limit
match: the arm waited at the pick for ever
match: the cell stopped and nothing said why

## Symptom

One move never arrives and the machine waits for ever; nothing says why. The operator finds the cell stopped and the screen shows a step that has been running for an hour.

## Cause

No state had a time limit. A target that cannot be reached, a hand that jammed or a sensor that stopped leaves the machine in the same state with nothing to end it.

A state that waits for an event can only end when the event comes. A target that cannot be reached, a sensor that stopped or a jam never sends it.

## Fix

Give every state a time limit and a fault code that names it. A move that never arrived then stopped the machine in fault 3 at tick 62.

```cpp
if (m.s != rc::arm::kPickDone && m.s != rc::arm::kPickFault && m.ticks > m.timeout) {
  m.fault = 3;
  rc::arm::enter(m, rc::arm::kPickFault);
}
```

The time limit for each state is worth choosing from a measured normal run with a margin, so it does not fire on a slow but good cycle.
