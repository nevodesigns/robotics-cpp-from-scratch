## Symptom

A station is started with a port that has a letter O in it and listens on port 0 or connects to the wrong one. Or the same option is given twice, once in a shell alias and once on the line, and the one nobody expected wins.

## Cause

`QCommandLineParser` checks the shape of a line and treats every value as text, so `--port abc` is accepted and `toInt()` of it is 0, and a repeated option keeps all its values and returns the last. Measured: **abc** was accepted and was **0**; `--port 1 --port 2` gave **2**, with 2 values.

## Fix

Convert through something that refuses, check the range, and refuse a repeated option:

```cpp
result.port = setting_int(QVariant(parser.value(port)), &ok);
if (!ok || result.port < 1 || result.port > 65535) { *err = "--port must be ..."; return false; }
```
