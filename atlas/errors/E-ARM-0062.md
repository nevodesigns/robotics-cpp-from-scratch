## Symptom

An arm in a fixed cell pauses to plan before every move.

## Cause

A fresh tree for each move found the free space again each time: about 2432 poses against 858 for a query on a roadmap.

## Fix

Build a roadmap once for the fixed scene and search it.

```cpp
roadmap_query(problem, roadmap, start, goal, 6);
```
