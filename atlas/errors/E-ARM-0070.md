match: a path made before an object moved is still free if it moved away and not if it moved onto the path
platforms: linux, windows

## Symptom

The arm follows a plan made some time ago through a place that has changed.

## Cause

Nothing said that the scene had changed since the plan was made. With a version, a move took the scene from 0 to 4 over four changes and the plan was stale; the recheck found the path free when the object moved 0.5 m away and not when it moved onto it.

## Fix

Record the scene's version with the plan and recheck the path (or replan) when it differs.

```cpp
if (plan_is_stale(plan_version, scene)) recheck();
```
