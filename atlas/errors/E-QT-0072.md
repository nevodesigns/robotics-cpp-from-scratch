## Symptom

QML code pushes a reading onto a list that is a property of a C++ object, and the C++ side never sees it. The same code works for one property and not for another that looks identical.

## Cause

A `QVariantList` property becomes a JavaScript array in QML, which is a copy. A `QStringList` is a sequence type that QML writes back. Measured on Qt 6.2: after one push onto each, the `QStringList` had **3** (1 changed signal) and the `QVariantList` **2** (0 signals).

## Fix

Do not push onto list properties. Give QML a function, or a model:

```cpp
Q_INVOKABLE void append(double value);
```
