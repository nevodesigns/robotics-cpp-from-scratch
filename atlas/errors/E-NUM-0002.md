id: E-NUM-0002
title: A value that wrapped around its type
match: (integer overflow|signed integer overflow|runtime error:.*cannot be represented)
platforms: linux, windows
teaches: 00-03-numbers-that-lie
---

## Symptom

A counter jumps from a large positive number to a large negative one, or an
encoder appears to travel a huge distance instantly.

## Cause

Whole number types have a fixed range. Exceeding it wraps to the other end rather
than saturating. The overflow is often in an intermediate result that is never
printed, such as a multiplication before a division.

## Fix

Use a wider type for intermediate results, or reorder the arithmetic so the large
value never exists. For counters that legitimately wrap, such as encoders,
compute the difference between readings in the counter's own type so the wrap
cancels out. Build with the asan preset, which reports signed overflow.
