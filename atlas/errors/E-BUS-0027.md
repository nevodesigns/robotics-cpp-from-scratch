title: A command retried against a server that forgets
match: a server that is asked twice does the work once and gives the same answer twice
match: over a link that loses 30 percent each way, retries make calls complete, and a server that remembers keeps them from running twice
platforms: linux, windows
teaches: 17-09-a-call-across-the-bus
---

## Symptom

A dispenser gives two portions, a counter is reset twice, or a command is carried out although the caller was told it had failed.

## Cause

A timeout means the caller does not know. With no retries, 155 of 300 calls were reported timed out while the work ran 214 times. Retries raise completions to 298 of 300, and a server that remembered ran the work 300 times, where one that forgot ran it 446 times.

## Fix

Key the server's memory by client and call number, and return the remembered answer for a repeat.

```cpp
const std::pair<int, int> key(request.client, request.id);
```
