title: A red object that comes out blue

## Symptom

Colours look wrong in a way that is hard to describe until somebody points at a
red object and says it is blue. Skin tones are odd, a green indicator reads
correctly, and a colour threshold tuned on one machine finds nothing on another.

Nothing reports an error anywhere.

## Cause

There is no natural order for the bytes of a colour pixel, and every combination
is in use. A camera hands you four bytes; which is red is a convention.

The bytes `32, 64, 200, 255`:

| read as | red | green | blue |
|---|---|---|---|
| B, G, R, A | **200** | 64 | 32 |
| R, G, B, A | **32** | 64 | 200 |

A mostly red pixel and a mostly blue one, from the same four bytes. Both
readings are valid data, so nothing anywhere can object.

**Green and alpha are in the same place either way.** So is grey. A test on a
grey card, a white balance check, or anything that looks at the green channel
passes under both conventions, which is how this survives to the field.

Common conventions worth knowing: many cameras and most Windows surfaces are
BGRA, most file formats and most of the web are RGBA, OpenCV is BGR, and a great
deal of embedded hardware is neither because it packs the channels into 16 bits.

## Fix

Name the order in the type and convert in one place.

```cpp
enum class ChannelOrder { rgba, bgra };
const Colour colour = colour_at(pixel, order_of_this_camera);
```

Then the order is a value that travels with the frame rather than an assumption
spread through the code, and pointing a different camera at it is a
configuration change.

**Ask the source rather than assuming.** Every capture API reports its format,
and the answer can change: a driver update, a different resolution, or a
negotiation that fell back to a second choice.

**Test with a colour that is not grey.** A pixel that is mostly red is the
smallest test that can tell the two apart, and it is one line.

**Check it at the edge, once.** A frame converted on the way in, with the order
recorded, means everything downstream sees one convention. Converting in five
places means four of them will eventually disagree.
