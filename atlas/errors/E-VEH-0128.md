title: A check that a bad sensor passes

## Symptom

A dead sensor reports a value that is not a number and the check on it passes.

## Cause

The check was written as a failure test, `age > limit`, which is false for a number that is not a number. A state of eight such values failed 8 checks when each is written as `age <= limit`.

## Fix

Write every check as 'ok when within the limit', so that anything that is not a number fails it, and test that.

```cpp
ok = s.scan_age_s <= lim.scan_max_s;
```
