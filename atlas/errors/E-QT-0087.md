## Symptom

A handler runs twice for each signal, or three times, and more the longer the program runs. Writing to a log shows the same line repeated.

## Cause

A connection is made each time `connect` is called, and nothing checks for an existing one. Code that runs again, when a panel is shown or a mode is entered, connects again. Measured: three connections gave **3** calls for one signal; `connect_once` gave **1**.

## Fix

Ask for a unique connection, and count it as made only if it was:

```cpp
QObject::connect(sender, signal, receiver, slot, Qt::UniqueConnection);
```
