id: E-QT-0075
title: A property set on nothing
match: setProperty on a name that does not exist returns false, creates a property of that name and changes nothing
match: expected refused.error
platforms: linux, windows
teaches: 11-06-the-property-set-on-nothing
---

## Symptom

A test sets a property and asserts that nothing changed, and passes. The property name has a typo. Or a test of a change fails to see one, because it set a different name from the one the interface reads.

## Cause

`QObject::setProperty` with a name that is not a declared property creates a dynamic property and returns false. Nothing reads it. Measured: `setProperty("widht", 300)` returned **false**, created the property, and `width` stayed **200**; reading `nothingLikeThis` was an invalid `QVariant`, **0** as a double.

## Fix

Write through something that knows what the object declares, and fail on a name that is not one:

```cpp
QQmlProperty property(object, name);
if (!property.isValid()) { result.error = "no property named " + name; return result; }
```
