## Symptom

A planner that has put the arm into a collision cannot tell which way to move it out.

## Cause

The check returned a boolean. A signed distance says how deep: with the floor at 0.4 m the arm was -0.160 m through it.

## Fix

Return the signed distance, and the capsule and obstacle it is for.

```cpp
const Clearance c = scene_distance(caps, scene, true);
```
