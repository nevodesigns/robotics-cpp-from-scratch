## Symptom

An arm in a fixed cell pauses to plan before every move. The cycle time includes a planning pause before every move.

## Cause

Each move grew a fresh tree and found the free space again: about 2432 poses checked, against 858 for a query on a roadmap built once.

A tree is built from scratch for each query and thrown away. In a scene that does not change, most of that work rediscovers the same free space. A roadmap keeps it.

## Fix

For a scene that does not change, build a roadmap once and search it for each query.

```cpp
const rc::arm::QueryResult q = rc::arm::roadmap_query(problem, roadmap, start, goal, 6);
```
