id: E-CAP-0020
title: A state with no answer for an event
match: a road blocked for eight seconds is waited out, one blocked for twelve sends the robot home with its load, and one blocked both ways asks for help
platforms: linux, windows
teaches: 21-07-a-delivery-not-a-route
---

## Symptom

The robot waits in the road for ever, or turns round with no word, because the code never decided what a blocked road means.

## Cause

A road blocked for 8 s was waited out (waited 8.0 s, delivered); for 12 s it was aborted after 10.1 s of waiting and the robot was home with 35.2 Wh; blocked both ways it was needs help at 19.1 m from home.

## Fix

Give every state an answer for every event.

```cpp
if (blocked_for_ > cfg_.blocked_timeout) state_ = MissionState::help;
```
