id: E-CPP-0006
title: A function modified a copy instead of the caller's object
match: unused parameter
platforms: linux, windows
teaches: 01-03-references-and-angles
---

## Symptom

A function that is supposed to change something appears to do nothing. The value
read back afterwards is unchanged, and no error is reported anywhere.

## Cause

C++ passes arguments by value by default, which copies them. The function
modified its own copy, and the copy was destroyed when the function returned.

## Fix

Take the parameter by reference, written as Type& name, when the function is
meant to modify it, and name the function so that the reader expects the change.
Use const Type& when the function only reads a large value, which avoids the copy
without allowing modification.
