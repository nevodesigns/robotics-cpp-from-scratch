id: E-QT-0070
title: An object marked as C++ owned with nobody to delete it
match: telling the engine that C\+\+ owns an unparented object keeps it, and then C\+\+ must delete it
match: expected g_alive to equal 3
platforms: linux, windows
teaches: 11-04-the-object-qml-collected
---

## Symptom

Memory grows with every call from QML, and the leak checker names the factory function. The collector does not touch these objects.

## Cause

`CppOwnership` says only that the engine will not delete the object. With no parent it has no owner at all. Measured: the object survived the collection (alive **3**) and had to be deleted by hand (**2**).

## Fix

Give it a parent as well, so that something deletes it:

```cpp
object->setParent(owner);
```
