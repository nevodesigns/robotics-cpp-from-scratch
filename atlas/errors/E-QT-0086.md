## Symptom

A command line option or a settings file says `auto` and the robot starts in the default mode, or says `Fault ` with a trailing space and starts in a mode nobody chose.

## Cause

`keyToValue` is exact, and a conversion that guesses (case folding, trimming, a number read as a name) accepts strings that were not written for it. Measured: `Auto` and `Idle` were read; `auto`, `AUTO`, `Auto `, the empty string, `Fault2` and `1` were refused, and the result was untouched.

## Fix

Return false on anything that is not an exact key, and do not touch the result:

```cpp
bool ok = false;
const int value = meta.keyToValue(name.toUtf8().constData(), &ok);
if (!ok) return false;
```
