title: A command that was applied twice because it was sent twice
match: a command whose acknowledgement is lost arrives twice, and is applied once, where applying every arrival would do it twice
match: expected link.duplicates_refused
platforms: linux, windows
teaches: 12-03-the-command-that-arrived-twice

## Symptom

The robot drives two metres when it was told one, or a gripper closes twice, only on a link that drops packets and never on the bench.

## Cause

A sender that retries what it has not heard an answer to cannot tell a lost command from a lost answer. A receiver that applies every arrival does the command twice in the second case. Measured: with the first acknowledgement of 10 commands lost, there were **20** arrivals, **10** applied by the receiver with **10** refused as duplicates, and a robot that applied every arrival would have done **20**.

## Fix

Number the commands, and apply a number once:

```cpp
if (seen_.count(seq) > 0) return false;     // acknowledge it, and do not apply it
```
