## Symptom

A learned driving policy passes every test, then fails on its first real run from a start a little unusual.

## Cause

Every test started where the demonstrations started. From starts like the demonstrations', the clone succeeded on 100 percent, as the expert did; that says the clone has learned the expert's states, nothing about the others.

The test set of 38-01 was split by episode, which is right for the error on single answers, but every episode came from the same kind of start.

## Fix

Test by driving from a spread of starts wider than the demonstrations', and compare with the expert from the same starts.

```cpp
const double cl = rc::learn::success_rate(task, &policy, seen, 0.6, 0.8, 100, seed, 300);
const double ex = rc::learn::success_rate(task, nullptr, seen, 0.6, 0.8, 100, seed, 300);
```

The expert's own rate from the same starts is the ceiling; some starts are lost whatever the policy.
