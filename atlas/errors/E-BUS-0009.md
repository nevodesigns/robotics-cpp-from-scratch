## Symptom

A robot drives to a position that is a velocity, because one program changed a message and the other did not.

## Cause

Bytes carry no meaning, and two programs can disagree about a topic without either noticing. A frame that starts with a type id from the message's name and version, and a length, gave four distinct answers to four bad frames: wrong_type, bad_length, bad_length and too_short. The published FNV-1a value for a, 0xE40C292C, checks the id function.

## Fix

Frame every message and check the answer.

```cpp
if (unframe(bytes, type_id("rc/msg/Pose2D"), payload) != FrameStatus::ok) reject();
```
