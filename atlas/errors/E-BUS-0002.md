id: E-BUS-0002
title: A subscriber removed while the list is being walked
match: a handler may unsubscribe itself or a later subscriber in the middle of a delivery, and nothing is skipped or called after it left
platforms: linux, windows
teaches: 17-01-topics-by-hand
---

## Symptom

A handler that unsubscribes itself makes the next subscriber miss the message, or the program crashes with an iterator that points at nothing.

## Cause

Erasing from a list changes it under the loop that is walking it. The bus copies the tokens when a message goes out and checks each is still subscribed before calling it. With a removing itself and b, the first message reached a and c (2 called), the log read a c, and the second reached c alone.

## Fix

Walk a copy, and check each entry is still there.

```cpp
for (Token token : tokens) {
  if (!still_subscribed(message.topic, token)) continue;
  // call it
}
```
