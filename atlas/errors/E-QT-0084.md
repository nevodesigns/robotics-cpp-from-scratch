## Symptom

A mode, a state or a unit that is an enum in C++ is zero everywhere in the interface, and nothing was reported. The QML reads naturally.

## Cause

QML knows an enum only through the meta object. An enum without `Q_ENUM_NS` (or `Q_ENUM`) is a C++ detail, and `Name.Value` for it is `undefined`, which converts to 0 or to nothing. Measured: with the macros `RobotMode.Auto` was **1** and `RobotMode.Fault` **9**; without, `PlainMode.Auto` was **undefined** and the file loaded.

## Fix

Declare the enum, and register the namespace:

```cpp
namespace robot_mode { Q_NAMESPACE enum class Mode { Idle, Auto }; Q_ENUM_NS(Mode) }
qmlRegisterUncreatableMetaObject(robot_mode::staticMetaObject, uri, 1, 0, "RobotMode", "names");
```
