## Symptom

A test fails one run in fifty, and by the time anyone looks it passes. The failing input is gone, and nobody can say what it was.

## Cause

The numbers came from something that gives different ones each run: the clock, or the machine's own source. A failure found with it cannot be found again.

A seeded generator gives the same numbers for the same seed. Seed 12345, the largest of 100 draws was 0.999863 at draw 32, and run again it was 0.999863 at draw 32.

## Fix

Seed from a number the test prints, and use that seed again to replay:

```cpp
Rng rng(seed);
std::cout << "seed " << seed << "\n";    // a failure report that includes this can be replayed
```
