## Symptom

A network with many hidden units learns no better than one with a single unit, and its hidden units all have the same weights after training.

## Cause

The weights started equal (often all zero). Units with the same weights compute the same activation, receive the same gradient and stay equal for ever, so the layer behaves as one unit. Gradient descent never breaks a symmetry it started with.

## Fix

Draw the starting weights at random, from a seed, at a scale that keeps the units out of saturation.

```cpp
rc::learn::Mlp net = rc::learn::make_mlp(16, 1.0, seed);
```

The seed makes the run repeatable; a different seed is a different starting network, and a result should hold over a few of them.
