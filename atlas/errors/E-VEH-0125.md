## Symptom

Every run has findings, so nobody looks at them any more.

## Cause

Thresholds without a measured false rate. Twenty clean runs with noise gave 0 false findings here because a span shorter than 2 s is dropped and the slip threshold sits at 70 percent.

## Fix

Measure the false rate on clean runs, and set the thresholds and the minimum span to keep it near zero.

```cpp
cfg.min_span = 2.0; cfg.slip_ratio = 0.7;
```
