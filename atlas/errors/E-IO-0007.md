## Symptom

Every frame fails its checksum, from the very first one. Not an occasional
failure, which would suggest a cable: all of them, immediately, on a link that
is otherwise framing correctly.

Or, more confusingly, frames pass in one direction and fail in the other.

## Cause

The two ends do not agree about which bytes the checksum covers. The candidates
are all reasonable and mutually incompatible:

- the payload only,
- the payload and the length,
- the payload, the length and the start byte,
- the payload and the checksum byte itself, which is the accidental one.

That last is the classic, and it comes from verifying with the obvious line:

```cpp
if (crc8(payload) != payload.back()) return false;   // the bug
```

`payload` still includes the checksum byte, so this computes the checksum of
something the sender never checksummed. It cannot ever match, which at least
makes it easy to spot compared with the alternatives.

The variant that passes in one direction and fails in the other is the same
mistake made in only one of the two implementations.

## Fix

Write down which bytes are covered, in a comment beside the code and in whatever
document describes the protocol, and compute over exactly those at both ends.

```cpp
const std::size_t body_size = payload.size() - 1;
const rc::span<const std::uint8_t> body(payload.data(), body_size);
if (crc8(body) != payload[body_size]) return false;
```

Covering the payload alone, with the checksum as the last byte inside the
frame's length, is a good default. The framing then needs no knowledge of the
checksum and the checksum needs none of the framing, so each can be tested on
its own.

Two related traps worth checking at the same time.

A payload too short to hold a checksum has not lost one, it never had one.
Returning true for it is how an empty frame gets trusted.

The length byte, if it is covered, is covered as it appears on the wire. A
sender that checksums the length it intended and a receiver that checksums the
length it received will differ on exactly the frames where it matters.
