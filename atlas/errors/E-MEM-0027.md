title: A container passed by value

platforms: linux, windows

## Symptom

A function that only reads a list of readings is called a hundred times a second, and the program allocates for each element each time. Changing a call site from a variable to a temporary makes it fast again.

## Cause

A parameter taken by value is a new vector. Passing a named vector copies it, every element, and the copy is thrown away at the end of the call. The signature looks the same as one that takes a reference except for a single `&`.

Measured with a vector of 50: **50** copies by value, **0** by const reference, and **0** copies and 0 moves of elements by value from `std::move`, since the vector took the other's buffer without touching its elements.

## Fix

```cpp
long total(const std::vector<Packet>& v);    // reads it, copies nothing
long total(std::vector<Packet> v);           // a function that keeps its own copy, and wants one
```

Take by value only on purpose, usually to store it, and then move it in.
