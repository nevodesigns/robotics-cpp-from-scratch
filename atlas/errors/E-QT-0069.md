## Symptom

A crash appears some time after QML calls a C++ factory function, in code that uses a pointer the factory kept: the object is gone. It comes and goes with how often the collector runs.

## Cause

An invokable that returns a `QObject*` with no parent hands it to the engine, and the collector deletes it when the JavaScript value is unreachable. Measured: 3 objects alive after the call and **2** after a collection, and the pointer C++ had kept was **gone**.

## Fix

Say who owns it. Give it a parent and mark it as C++ owned:

```cpp
object->setParent(owner);
QQmlEngine::setObjectOwnership(object, QQmlEngine::CppOwnership);
```
