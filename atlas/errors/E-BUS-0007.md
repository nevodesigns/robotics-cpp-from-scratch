id: E-BUS-0007
title: A struct sent as it sits in memory
match: integers are written low byte first, one after the other with nothing between them
match: the wire size is the fields added up, and a struct written as it sits in memory is not
match: a message round trips exactly, a double to the last bit, a string with its length
platforms: linux, windows
teaches: 17-03-messages-as-bytes
---

## Symptom

Two programs built by different compilers or for different machines read each other's messages as garbage, or the same program stops working when a field is added.

## Cause

A struct's layout is the compiler's choice: a byte, a double and a 16 bit count are 1 + 8 + 2 = 11 bytes of fields and were 24 bytes in memory on the compiler that built this lesson, because of padding. The byte order is the machine's. A written layout, little endian with nothing between the fields, was 11 bytes and round tripped a double of -0.1234567890123456 exactly.

## Fix

Write each field by hand, in a fixed order and width.

```cpp
w.put_u8(kind);
w.put_f64(value);
w.put_u16(count);
```
