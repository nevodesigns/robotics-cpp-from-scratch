## Symptom

A driver publishes to a node that is still being configured, or the whole robot refuses to start because the logger's disk is full.

## Cause

Two passes: every node is configured in order and only then activated, so that nothing produces before the consumers exist. An optional node that failed to configure was left out with the plotter that needed it, and driver, filter and controller came up active, with the report listing logger and plotter as skipped.

## Fix

Configure everything, then activate everything, and mark the nodes that are not worth stopping for as optional.

```cpp
l.add("logger", {{"driver"}}, false);
```
