## Symptom

A test reads an expression from QML and gets an empty value, which compares equal to zero or to the empty string, and passes.

## Cause

`QQmlExpression::evaluate` returns an empty `QVariant` on error and keeps the error in the expression. A test that does not ask for it has read nothing. Measured: an undefined name was `ReferenceError: nothingCalledThis is not defined`, a syntax error was `SyntaxError`, a throw was `Error: boom`.

## Fix

Ask for the error, and make it part of the result:

```cpp
if (query.hasError()) { result.error = query.error().description(); result.value = QVariant(); return result; }
```
