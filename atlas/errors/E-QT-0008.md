id: E-QT-0008
title: CMake cannot find Qt6 at all
match: Could NOT find Qt6 \(missing: Qt6_DIR\)
match: By not providing "FindQt6.cmake"
match: could not find a package configuration file provided by "Qt6"
platforms: linux, windows
teaches: 09-01-the-qt-object-model
---

## Symptom

Configuration stops before any compiling happens:

```text
CMake Error at CMakeLists.txt:12 (find_package):
  By not providing "FindQt6.cmake" in CMAKE_MODULE_PATH this project has asked
  CMake to find a package configuration file provided by "Qt6", but CMake did
  not find one.

  Could not find a package configuration file provided by "Qt6" with any of the
  following names:

    Qt6Config.cmake
    qt6-config.cmake
```

Read the second line rather than the first. CMake is not saying Qt is broken, it
is saying it never found a Qt to look at.

## Cause

Two different situations produce the same message, and they have different
fixes.

Qt is genuinely not installed. On Linux this is the usual one.

Or Qt is installed somewhere CMake does not search, which is the usual one on
Windows, because the Qt installer puts it under a versioned path such as
`C:\Qt\6.5.3\msvc2019_64` and tells nothing else about it.

This entry is not `E-QT-0007`. That one is Qt6 found, `Widgets` not, which is a
missing OpenGL development package rather than a missing Qt.

## Fix

On Ubuntu:

```
sudo apt install qt6-base-dev libgl1-mesa-dev
```

Both, not just the first. The second is what `E-QT-0007` is about, and
installing them together saves meeting it next.

On Windows, point CMake at the Qt you installed:

```
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.5.3/msvc2019_64"
```

The path must be the compiler specific directory, not `C:/Qt` and not
`C:/Qt/6.5.3`, because `Qt6Config.cmake` lives inside it under `lib/cmake/Qt6`.
Use forward slashes; CMake accepts them on Windows and backslashes in an
unquoted argument are escapes.

Then delete the build directory and configure again. A failed search is cached,
so a second attempt in the same directory reports the same failure however
correct the fix was.

Qt is optional in this curriculum. Everything up to phase 09 builds without it,
and `rcpp doctor` reports whether it is present rather than assuming.
