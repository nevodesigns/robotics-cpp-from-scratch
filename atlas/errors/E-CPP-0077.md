title: A snapshot named by when it was made, or by its listing order
match: a snapshot has the same name however its files are listed, and a different one if anything changes
match: expected this to be true: snapshot_id
platforms: linux, windows
teaches: 00-11-a-name-made-from-the-content

## Symptom

Two copies of a project are the same, byte for byte, and a tool says they differ. Or the other way: two copies differ by one file and the tool says they are the same.

## Cause

The name was made from something other than the content: the time it was made, or the order a directory happened to list its files in. A folder has no order. Any
name that depends on one will change when nothing did.

The suite lists the same three files in two orders and the snapshot names are equal. Editing one file, renaming one, or removing one each give a different name, and so does an empty snapshot against a full one.

## Fix

Name each file by its name and content together, and combine the names with an operation that does not care about order:

```cpp
combined ^= file_id(files[i]);                       // xor does not care
return scramble(combined ^ static_cast<Id>(count));
```
