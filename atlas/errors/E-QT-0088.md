## Symptom

The log fills with `ReferenceError` or `TypeError` from QML files that are not on the screen, once for each time an item was reloaded, and the count grows as the user moves about.

## Cause

A connection made with `signal.connect(function)` is not removed when the item that made it is destroyed, and the handler runs with the names of a context that has gone. Measured: after three reloads one signal ran the live handler **1** time and produced **3** warnings, each a `ReferenceError`.

## Fix

Make the connection part of the item, with a `Connections` element:

```qml
Connections { target: sensor; function onReading() { tally.hit() } }
```
