## Symptom

The loop built on the servos will not run faster than a few hundred updates a second, or much less.

## Cause

The wire sets it: 2.98 ms for six servos at 1 Mbit/s, 14.3 ms at 115 200 bit/s, 5.68 ms for twelve.

## Fix

Use the highest baud rate the servos take, send one goal packet to all (a sync write), read only what is needed, and design the loop for the rate you get.

```cpp
bus_cycle_seconds(bus, n_servos);
```
