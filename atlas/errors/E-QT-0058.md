## Symptom

A chart of a few hundred columns uses a whole core to add one sample a millisecond, and most of the time is in the paint event.

## Cause

Calling `update()` with no rectangle marks the whole widget, and a `paintEvent` that does not look at the rectangle in the event draws the whole widget. Measured: a full update went over **300** columns, and one sample over **1**.

## Fix

Mark the rectangle, and loop only over what it covers:

```cpp
for (int c = event->rect().left(); c <= event->rect().right(); ++c) { ... }
```
