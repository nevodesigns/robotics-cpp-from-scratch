## Symptom

A "stop" command arrives with wheel speeds in it from the last time the struct was used, and one part of the program obeys them. A "drive" arrives with its speeds never set. Each looks like a valid command.

## Cause

A struct with a `kind` number and a field for everything any kind needs can hold combinations that mean nothing: a stop with speeds, a drive with none, a kind value that is none of the three. Nothing in the type
says which fields are meant for which kind, so every user has to remember.

A `std::variant<Stop, Drive, SetLimit>` holds exactly one of them. Measured: a default-constructed command held the first, `Stop` (index 0); after assigning a `Drive` it held index 1; `get_if<SetLimit>` gave `nullptr` for it, and `get<SetLimit>`
threw `std::bad_variant_access`, so a wrong guess is an answer and not a quiet misreading.

## Fix

```cpp
using Command = std::variant<Stop, Drive, SetLimit>;
```

Each kind has its own struct with only the fields it needs.
