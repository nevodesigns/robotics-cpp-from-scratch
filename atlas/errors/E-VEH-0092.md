## Symptom

The steering jumps at each kink of the path.

## Cause

Stanley follows the path exactly: with no lookahead its heading error is a step where the path has a corner. It does hug a bend (0.036 m at most off the path).

## Fix

Smooth the path first (26-03), or use pure pursuit where the path has kinks.

```cpp
cfg.method = kStanley; // on a smoothed path
```
