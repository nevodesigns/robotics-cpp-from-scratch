## Symptom

The same top speed is fine on the long curves and a slide in the tight ones. The speed limit was set on a long, gentle curve.

## Cause

The speed limit did not depend on the bend. The sideways acceleration is speed squared times curvature, so the limit is sqrt(mu g / kappa): 1.81 m/s on this gravel circle, more on a gentler one.

The sideways acceleration is speed squared times curvature, so the speed that a bend allows falls as the curvature rises. A fixed speed limit is right for one curvature only.

## Fix

Make the speed limit a function of the curvature.

```cpp
const double v = std::min(v_cruise, rc::vehicle::max_speed_for_curvature(cell, heading, curvature));
```
