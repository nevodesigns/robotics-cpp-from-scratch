## Symptom

Repeating the calibration gives a different track each time.

## Cause

The variation of the floor from spin to spin (the efficiency varying by 3 percent) is not cancelled by direction, only averaged. One spin each way had a spread of 0.0034 m and four 0.0019 m.

## Fix

Use several spins each way and report the spread with the estimate.

```cpp
const Spread s = spread_of(estimates);
```
