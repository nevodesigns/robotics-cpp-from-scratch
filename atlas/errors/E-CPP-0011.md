id: E-CPP-0011
title: Cannot call a member function on a const object
match: passing .* as 'this' argument discards qualifiers
match: the object has type qualifiers that are not compatible with the member function
platforms: linux, windows
teaches: 03-01-classes-and-invariants
---

## Symptom

A perfectly ordinary getter refuses to compile when the object is const, with a
message about discarding qualifiers or incompatible type qualifiers on this.

## Cause

The member function is not marked const, so the compiler must assume it might
modify the object. It cannot allow that through a const reference, which is what
you get when an object is passed as const Type&.

## Fix

Mark every member function that does not modify the object:

```cpp
int count() const { return count_; }
```

The const goes after the parameter list and before the body. Apply the rule
everywhere rather than case by case: a class whose reading functions are not
const is awkward to use and will be corrected by whoever meets it next.

If a function genuinely needs to change something while remaining logically
const, such as a cache, mark that member mutable rather than dropping the const.
