## Symptom

Values computed for a policy change when the computation is run for longer, and a policy chosen from them changes too.

## Cause

The sweeping stopped after a fixed number of passes instead of when the values had settled. Each sweep moves information one step further from the rewards, so a far cell needs many sweeps; with a discount near one, many more. The random policy here took 242 sweeps to settle.

## Fix

Sweep until the largest change of any value in a sweep is below a tolerance, and report how many sweeps that took.

```cpp
int sweeps = 0;
const auto V = rc::learn::evaluate_policy(g, policy, 0.95, 1e-9, &sweeps);
```

A settled value satisfies its own equation: check one cell against move_value.
