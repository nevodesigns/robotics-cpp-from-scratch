id: E-QT-0062
title: Images of different sizes called equal
match: images of different sizes never match, whatever their pixels are
match: expected d.size_mismatch
platforms: linux, windows
teaches: 10-12-the-pixel-that-differed
---

## Symptom

A chart test passes after the window was resized, because the new image is bigger and the old part still matches.

## Cause

A loop over the width and height of the smaller image compares only what both have. Measured: 100 by 50 against 100 by 51, both white, was a size mismatch and matched at no tolerance and no count.

## Fix

Compare the sizes first:

```cpp
if (a.size() != b.size()) { d.size_mismatch = true; return d; }
```
