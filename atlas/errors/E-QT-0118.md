## Symptom

A configuration file that was copied from the build machine sends Qt, or the station, to a directory that does not exist on the robot, and the failure is a plugin that cannot be found.

## Cause

A file written on the build machine names that machine. Measured: a `qt.conf` with `/home/builder/Qt/6.2/gcc_64`, `C:\Qt\6.5.3\msvc2019_64\bin` and `C:/Qt/6.5.3/data` gave **3** stray paths; a relative path and one that existed were not.

## Fix

Look for absolute paths that do not exist where the check runs:

```cpp
for (const QString& path : path_tokens(text)) if (!QFileInfo::exists(path)) report.stray_paths.append(name + ": " + path);
```
