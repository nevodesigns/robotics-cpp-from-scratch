id: E-CPP-0007
title: Off by one, reading past the end of an array
match: (AddressSanitizer|ERROR).*(heap|stack)-buffer-overflow
match: index .* out of bounds
platforms: linux, windows
teaches: 01-04-arrays-and-spans
---

## Symptom

A wrong value appears at the last element, or the program crashes, or a
sanitizer reports a buffer overflow. Without a sanitizer it may simply return a
plausible wrong number and never crash at all.

## Cause

Array positions run from zero to count minus one. A loop that runs to count, or
an index computed with an extra plus one, reads memory that belongs to something
else.

## Fix

Loop from zero while the index is strictly less than the count. Prefer a range
based for loop, or a std::span, which both know the real size. Build with the
asan preset, which turns this class of silent bug into a clear report:
cmake --preset asan
