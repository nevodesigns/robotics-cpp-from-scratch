id: E-QT-0002
title: connect returns false and the slot never runs
match: QObject::connect: No such (signal|slot)
match: QObject::connect: signal not found
platforms: linux, windows
teaches: 09-01-the-qt-object-model

## Symptom

The program builds and runs, but nothing happens when the signal is emitted. Qt
may print a warning about no such signal or slot.

## Cause

The signal and the receiver do not match. Usually the signature differs, an extra
or missing argument type, or the string based connect syntax was used with a
typo, which cannot be checked at compile time.

## Fix

Use the pointer to member syntax, connect(&sender, &Sender::signalName,
&receiver, &Receiver::slotName), which the compiler checks. Confirm the receiver
still exists when the signal is emitted: a destroyed receiver silently
disconnects, which is a feature, not a bug.
