title: A rethrow that changes the type
match: throw; keeps the original type, and throw e; does not
match: expected seen to equal

## Symptom

A function catches an error to note something, rethrows it, and the caller's handler for the specific type no longer runs. The general handler gets it instead.

## Cause

`throw e;` throws a new exception made by copying the variable `e`, from its declared type. If `e` was a `const std::exception&`, what is thrown is a `std::exception`. A bare `throw;` rethrows the object that
was caught, with its own type.

Measured: rethrown with `throw e;` the caller saw **"cut down to exception"**; with `throw;` it saw **"still invalid_argument"**.

## Fix

```cpp
} catch (...) {
  *failed_index = i;     // note what you need to note
  throw;                 // and let the same error carry on
}
```
