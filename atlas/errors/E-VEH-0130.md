## Symptom

Any fault stops the vehicle, or no fault changes what it does. A minor sensor loss stops a whole mission, or a scanner loss does nothing.

## Cause

Every loss had the same response. Losing the scanner needs a stop (mode 3); losing GNSS needs only a reduced mode (1); two losses together cost a creep (2).

Each loss takes away a different ability: no scanner, no protection; no GNSS, a position that drifts; no gyro, a heading that drifts. The right response depends on what was lost and what is left.

## Fix

Give each loss its own mode, count the losses, and let the position's sigma move the mode on as well.

```cpp
const rc::drive::Mode m = rc::drive::required_mode(health, policy);   // kFull, kReduced, kCreep, kSafeStop
```
