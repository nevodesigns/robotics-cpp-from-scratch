title: A best effort publisher and a reliable subscriber
match: reliability: a reliable offer meets either request, and a best effort offer meets only a best effort one
match: a camera driver in sensor data profile and a node that subscribes with the default profile are never connected
platforms: linux, windows

## Symptom

The publisher is running and the subscriber is running, the topic names match, and the subscriber never gets a message and logs nothing useful.

## Cause

A best effort publisher cannot meet a reliable subscriber's request, so the two are not connected and nothing is delivered. The rule is not symmetric: reliable offered meets either request, best effort offered meets only best effort. A camera driver in the sensor data profile and a subscriber with the default profile were not connected, with one reason named, while the best effort viewer beside it was.

## Fix

Make the subscriber's request no stronger than the publisher's offer.

```cpp
Endpoint viewer{"viewer", "image", sensor_data_profile()};
```
