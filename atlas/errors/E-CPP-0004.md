id: E-CPP-0004
title: An angle that grows without limit
match: theta.*(nan|inf)
platforms: linux, windows
teaches: 00-04-first-motion
---

## Symptom

A heading value keeps climbing: 7.0, then 13.0, then 400.0. The robot still
points in a sensible direction, but comparisons between headings give nonsense
and controllers behave strangely.

## Cause

Adding a rotation to an angle every time step, without ever bringing it back into
range. The angle remains geometrically correct but numerically unbounded, so the
difference between two headings is no longer the turn between them.

## Fix

Wrap the angle back into the range minus pi to pi after every update, using
wrap_angle. Wrap the difference too when comparing two headings, which is what
shortest_turn does in lesson 01-03.
