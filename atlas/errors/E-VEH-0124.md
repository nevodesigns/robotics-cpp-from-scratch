## Symptom

After a bad run someone scrolls through the log by hand for the moment it went wrong.

## Cause

The log held the rows and nothing read them. The faults a vehicle has (stuck, slip, off path, drain, a gap in time) have signatures that a program can find.

## Fix

Read every run for those faults and put the spans with their times in the report. Read that way, a run with five faults put in gave all 5, each within 1.8 s of where it began.

```cpp
const std::vector<rc::drive::Finding> f = rc::drive::analyse_log(rows, rc::drive::DoctorConfig());
```
