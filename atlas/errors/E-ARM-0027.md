## Symptom

After calibration the tool is in the right place and a fitted link length is not the one that was measured with a ruler.

## Cause

Some corrections give the same tool place whatever the joints do (the offsets along joints 2 and 3, which are parallel, differed by 0.000000000000 m), so the measurements cannot separate them.

## Fix

Use the calibrated table for the tool's place only, drop or fix the dependent corrections before reading values off it, and measure the lengths another way if they matter.

```cpp
// d2 and d3 move the tool together
```
