## Symptom

An object starts with a default where a value was meant. The log has one line, `Setting initial properties failed`, which nobody read.

## Cause

The engine reports a name that the object does not declare as a warning and goes on with the others. Measured: `limt`, `nothing_like_this` and `limit` together were null with `no property named limt` and the other, and not the right one.

## Fix

Check every name first, and refuse them together:

```cpp
if (!QQmlProperty(object, key).isValid()) unknown += "no property named " + key + "\\n";
```
