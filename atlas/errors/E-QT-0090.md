title: A Repeater that makes an item for every row
match: a Repeater makes a delegate for every row, and a ListView only for the rows it shows

platforms: linux, windows

## Symptom

An interface takes seconds to appear and uses memory in proportion to the length of a list, and the CPU is busy before anything has been drawn.

## Cause

A `Repeater` makes a delegate for each row of its model when the model is set, whether or not anyone can see it. Measured: 10000 rows were **10000** delegates, all alive; a `ListView` over the same rows made **21**.

## Fix

Use a view that makes only what it shows:

```qml
ListView { model: rows; delegate: Item { ... } }
```
