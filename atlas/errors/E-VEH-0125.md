## Symptom

Every run has findings, so nobody looks at them any more. The findings are all in the first and last second of every run, or in turns.

## Cause

The thresholds were set without a measured false rate. A detector that cries wolf on clean runs is ignored when it is right.

Every threshold has a false rate on clean data. A detector whose false rate is not measured cries wolf in the places where clean data is noisy, and its real findings are lost among them.

## Fix

Measure the false rate on clean runs, and set the thresholds and the shortest span to keep it near zero. Twenty clean runs with noise gave 0 false findings, because a span shorter than 2 s is dropped and the slip threshold is 70 percent.

```cpp
rc::drive::DoctorConfig cfg;
cfg.min_span = 2.0;
cfg.slip_ratio = 0.7;
```
