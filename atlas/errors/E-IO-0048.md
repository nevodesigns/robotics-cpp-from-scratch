## Symptom

After the station has run for a long time, a command is refused as a duplicate, or accepted twice, or an acknowledgement for an old command acknowledges a new one.

## Cause

A 16 bit number repeats after 65536 commands, and the window of remembered numbers has to be smaller than that and larger than the commands outstanding. An answer for a number that is not waiting must be refused, or it will end the wrong thing. Measured: **70000** commands used **65536** numbers with none twice in a row; a second `ack` and one for a number never sent were refused; a window of two forgot a number after two more.

## Fix

Let the type wrap, and refuse an answer that has nothing to match:

```cpp
const std::uint16_t seq = next_++;
bool ack(std::uint16_t seq) { return pending_.erase(seq) > 0; }
```
