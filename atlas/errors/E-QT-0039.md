## Symptom

A limit of 3.7 in a settings file becomes 4, and a count of three thousand million becomes minus one thousand two hundred ninety-four million. A negative count read as unsigned becomes four thousand million. The program checked `ok` and it was true.

## Cause

`QVariant::toInt` rounds a double and wraps one that is too big, and reports the conversion as having worked. `ok` means a conversion was done and not that the value survived it.

Measured on Qt 6.2: `QVariant(3.7).toInt()` was **4** with ok true, `QVariant(-3.7).toInt()` was **-4**, `QVariant(3e9).toInt()` was **-1294967296** with ok true, and `QVariant(-1).toUInt()` was **4294967295** with ok true.

## Fix

Take a double as a whole number only if it is one and fits, and refuse everything else:

```cpp
if (d == std::floor(d) && d >= min_int && d <= max_int) { *ok = true; return static_cast<int>(d); }
```
