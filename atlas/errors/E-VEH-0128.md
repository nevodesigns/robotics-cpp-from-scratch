title: A check that a bad sensor passes
match: the vehicle started with a dead sensor and the checklist said go
match: a comparison with nan passed the check
match: a good vehicle passes all ten checks and may go
match: a number that is not a number fails its check
platforms: linux, windows

## Symptom

A dead sensor reports a value that is not a number, and the check on it passes. The sensor was unplugged and every check passed.

## Cause

The check was written as a test for failure, age > limit, which is false for a value that is not a number. A state of eight such values passed every check written that way, and failed 8 when each was written as age <= limit.

A comparison with NaN is false whichever way it is written. A check written as a test for failure, age > limit, is false for NaN and passes; written as a test for success, age <= limit, it is false for NaN and fails, which is what a dead sensor should do.

## Fix

Write every check as ok when within the limit, so that anything that is not a number fails, and test with one.

```cpp
const bool ok = s.scan_age_s <= lim.scan_max_s;   // NaN fails
```
