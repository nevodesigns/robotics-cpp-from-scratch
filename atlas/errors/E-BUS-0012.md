id: E-BUS-0012
title: A restart that looks like a heartbeat
match: one that comes back after being gone appears again, and one that restarts without a gap is told apart by its incarnation
platforms: linux, windows
teaches: 17-04-who-is-out-there
---

## Symptom

A node restarts quickly, nobody is told, and its subscribers go on holding state that belonged to the old one.

## Cause

A node that restarts inside the lease is never gone from the table's side: it only ever sent a heartbeat. A new incarnation number each start is how to tell. After being gone the table said appeared; a new incarnation inside the lease gave one restarted event, and the next heartbeat with that same incarnation gave none.

## Fix

Send an incarnation with every announcement and report a change.

```cpp
if (incarnation != e.incarnation) queue(DiscoveryEvent::Kind::restarted, name);
```
