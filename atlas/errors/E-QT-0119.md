title: A deployment check that was run where everything exists
match: a folder that does not exist has everything missing and no crash, and nothing asked for is nothing missing
match: the paths in a text are found as written on either system, up to a space, comma, semicolon or quote
platforms: linux, windows
teaches: 12-09-the-machine-without-qt

## Symptom

The check passes, the folder is shipped, and the robot cannot start: every path in the folder existed on the machine that ran the check.

## Cause

A check of a path asks whether it exists here. On the build machine it always does. Measured: a folder that did not exist had **4** of **4** patterns missing and no crash; paths were found as written on either system, **4** in a line; none in a relative setting.

## Fix

Run the check on a machine, or a container, that has only what will be shipped:

```
rcpp-check /opt/station-1.4     # on a clean machine
```
