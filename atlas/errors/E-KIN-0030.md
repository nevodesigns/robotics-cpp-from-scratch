## Symptom

An arm model built from a datasheet is a few centimetres off everywhere, and more off when joints are bent. At zero angles it is exact.

## Cause

The standard and the modified conventions use the same four letters and different products. The numbers of one are a different arm in the other. Measured: one table and one set of angles put the tools **0.626211** m apart, and a flat two-row table **0.244589** m; at zero angles they agreed.

## Fix

Carry the convention with the table, and make the choice an argument:

```cpp
rc::kin::dh_chain(rows, q, rc::kin::Convention::kModified);
```
