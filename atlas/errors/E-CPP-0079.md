## Symptom

A project saved after every change uses a hundred times the space of the project. Backing up a folder of copies takes longer each day.

## Cause

Every copy stores every file, including the ninety-nine that did not change. Without a name made from the content there is no cheap way to see that two files are the same
file, so each copy has to be kept.

With names made from the content, equal files are recognised at once. Two versions of a hundred files with one edited: **200 files listed, 101 different contents** to store.

## Fix

Store each content once, under its name, and let a version be a list of names:

```cpp
std::set<Id> distinct;   // the contents that actually need keeping
for (const File& f : version) distinct.insert(content_id(f.text));
```
