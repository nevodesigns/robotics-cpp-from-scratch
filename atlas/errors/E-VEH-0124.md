## Symptom

After a bad run someone looks through the log by hand for the time it happened.

## Cause

The log held the rows and nothing read them. Reading it for five faults found all 5 put in a run, each within 1.8 s of where it began.

## Fix

Read every run for the faults a vehicle has (stuck, slip, off path, drain, gap) and put the spans with times in the report.

```cpp
const auto findings = analyse_log(rows, DoctorConfig());
```
