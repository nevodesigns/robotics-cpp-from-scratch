title: A grasp taken as made because the hand closed
match: the hand closed and the machine went on
match: the gripper reported closed with nothing in it
match: the grasp check is true for the part's width and false for a closed hand or a wrong part
platforms: linux, windows
teaches: 31-02-picking-and-placing-in-order

## Symptom

The hand closes fully, the machine goes on, and it carries nothing to the place.

## Cause

Closed was taken as holding. A hand closed on the part has the part's width between its fingers, within a tolerance; one closed on nothing has a gap near zero; one closed on the wrong thing has another width.

## Fix

Compare the gap with the part's width within a tolerance before lifting, and keep watching it while the part is carried: a part that fell was seen at once and stopped the machine in fault 2.

```cpp
const bool ok = rc::arm::holding(in.width, m.obj_width, m.tol);
```
