## Symptom

The program starts on the wrong backend, or with a loss of 2, or a delay of one and a half ticks, because one line of the configuration was wrong and the rest were used.

## Cause

A configuration of 8 lines each wrong (backend = hardware, link_delay = 1.5, loss = 2, noise = -1, seed = 0, an unknown setting, a line with no =, watchdog = -2) gave 8 errors with line numbers 1 to 8 and changed nothing. A configuration with no backend was refused with backend is required, and backend=sim alone, with defaults for the rest, was accepted.

## Fix

Report every error and leave the settings alone on any.

```cpp
if (!result.errors.empty()) return result;
out = parsed;
```
