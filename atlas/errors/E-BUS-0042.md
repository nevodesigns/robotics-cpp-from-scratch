id: E-BUS-0042
title: Callbacks that wait for a thread or a group and are not counted
match: more callbacks than threads wait for a thread even when their group allows them to overlap
match: a callback blocked by its group does not hold up the others behind it, and one that never gets to run is reported
platforms: linux, windows
teaches: 17-14-one-thread-or-many
---

## Symptom

A reentrant group was expected to run everything at once and the fourth callback is late, or a latency report says 0 because the late ones never ran.

## Cause

Threads are a limit as well as groups. Four 10 tick callbacks in a reentrant group started at 0 0 10 10 on two threads, and 0 0 0 10 on three. A callback blocked by its group did not hold up one in another group behind it (100 and 2), and one that never started counted as having waited 49 of 50 ticks.

## Fix

Count never started callbacks as having waited the whole run.

```cpp
const int w = runs[i].started < 0 ? limit - tasks[i].ready_at : runs[i].waited;
```
