## Symptom

A delegate shows nothing, or its text is blank, and the log says `ReferenceError: value is not defined`. Or the program crashes on a row that is one past the end.

## Cause

A delegate reads a role by the name `roleNames` gives it, and a model without names has none. And `data` is called with indexes that are not rows. Measured: with the names, the second delegate read **20.5** through `value`, and `data` was an empty `QVariant` for row 2 of 2, row 99, an invalid index and an unknown role.

## Fix

Name the roles, and check the index before using it:

```cpp
names[ValueRole] = "value";
if (!index.isValid() || index.row() < 0 || index.row() >= rowCount()) return QVariant();
```
