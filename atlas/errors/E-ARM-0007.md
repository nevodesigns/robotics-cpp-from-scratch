## Symptom

A tool velocity command moves the arm in a plausible but wrong direction, more in some poses than in others. The direction error is largest in poses far from home.

## Cause

Each joint's axis was taken from the wrong frame. In the standard convention a joint turns about the frame before its row, in the modified convention about the frame after; reading a modified table with the standard rule put the Panda's Jacobian 1.29 out.

Each column of the Jacobian is built from a joint's axis and its position. The two conventions put the joint's axis on different frames, and taking it from the wrong one gives a column for a different axis, wrong more in some poses than others.

## Fix

Take the axis from the frame the convention says, and keep a finite difference Jacobian as a test of the analytic one.

```cpp
const rc::arm::Jacobian j = rc::arm::jacobian(table, q, base, tool, table.convention);
```
