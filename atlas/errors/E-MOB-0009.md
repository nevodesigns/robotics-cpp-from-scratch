## Symptom

With the target hemmed in, the base drives to a spot next to an obstacle and stops against it, or the arm reaches through a wall. In simulation, with an empty room, it never happens, so the code that should handle it is never run.

## Cause

The choice always returned something, even when nothing was free. With obstacles all round the target, 0 of the 252 candidate places were free.

A function that returns the best of a list returns something whenever the list is not empty. If the candidates are scored and not filtered, an occupied place with a low score is still the best of the lot, and the base drives to it.

## Fix

Return none when nothing is free, and make the caller ask for more room, try another approach, or give up and say so.

```cpp
const rc::mobile::ParkChoice c = rc::mobile::choose_park(m, ring, target, current, obstacles, n, p);
if (!c.found) ask_for_help();
```

Test the choice with the target ringed by obstacles, and check that found is false.
