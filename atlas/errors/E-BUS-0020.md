id: E-BUS-0020
title: A late joiner on a volatile publisher
match: durability: a transient local offer meets either request, and a volatile offer cannot give a late joiner what it asks for
platforms: linux, windows
teaches: 17-07-will-they-talk

## Symptom

A node asks for the last map when it starts and never gets one, while the publisher is up and the topic name is right.

## Cause

A volatile publisher remembers nothing, so it cannot meet a transient local request: the pair is not connected. A transient local offer meets either request. The check named the reason: durability, offered volatile, requested transient local.

## Fix

Make the publisher transient local, as the map server's profile is.

```cpp
Qos q = latched_profile();   // reliable and transient local
```
