## Symptom

The station is closed and a timer sends a command to a link that is gone, or it is shipped without a library, or with a module whose licence nobody looked at.

## Cause

The parts were started in an order and each has a way to be stopped. A close that is not recorded as each part starts leaves one running. And shipping is a check as much as closing is. Measured: `stop()` closed **retries, monitor, link**, once, and **0** commands reached the robot after; the modules **Core and Network** had **0** licence findings; a folder with a library removed reported exactly that library.

## Fix

Record how to stop each part as it starts, and check what is shipped:

```cpp
retry_.start();
shutdown_.add("retries", [this] { retry_.stop(); return true; });
```
