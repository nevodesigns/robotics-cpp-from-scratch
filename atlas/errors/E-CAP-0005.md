match: a plan of the building gives a map in which walls and floor are both decided, and the sensor sees a wall where the plan has one
platforms: linux, windows
teaches: 21-02-a-rover-in-a-building

## Symptom

The robot has a supervisor and still hits people, because the thing that would tell the supervisor was never connected.

## Cause

With somebody stepping out, the rover with the limiter had 0 ticks in contact and a closest approach of 0.16 m. The one with the supervisor only had 144 ticks in contact, 7.2 s, the same as the one with neither.

## Fix

Connect a sensor to the supervisor's range cap.

```cpp
in.range_cap = limit_speed(top, front, rear, limiter_config);
```
