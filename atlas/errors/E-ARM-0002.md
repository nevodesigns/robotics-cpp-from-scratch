## Symptom

An arm built from a published table is right in its home pose and wrong in others, or wrong by a plausible amount.

## Cause

The table was written for one convention and read in the other. Standard and modified Denavit-Hartenberg tables put the same four numbers in a different order of operations, and the same row gave frames 0.170 m apart.

## Fix

Write the convention with every table and keep one function for each. Test the tool's position at two or three poses against a measurement or the maker's own numbers, not only at home.

```cpp
const rc::arm::Pose link = t.convention == rc::arm::kModified ? rc::arm::dh_modified(a, alpha, d, theta)
                                                              : rc::arm::dh_standard(a, alpha, d, theta);
```
