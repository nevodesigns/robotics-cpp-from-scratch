## Symptom

An element has zero size, or is anchored nowhere, and there is no error, no
warning, and nothing on stderr. Connecting to `QQmlEngine::warnings` produces
nothing either.

## Cause

The binding ran, and produced a value that is legal and wrong.

`0/0` in JavaScript is `NaN`. Assigned to a `real` property it becomes zero.
`undefined` assigned to a number becomes zero. `anchors.fill: parent` on an item
whose parent is null does nothing at all. None of these is an error by any
definition QML has, so nothing is reported by any channel.

Measured, with the warnings signal connected:

| case | loaded | errors | warnings | width |
|---|---|---|---|---|
| zero divided by zero | yes | 0 | 0 | 0 |
| undefined assigned to a number | yes | 0 | 0 | 0 |
| anchors against a parent it has not got | yes | 0 | 0 | 0 |

This is the third tier, and it is the reason the first two are not enough. The
rule the twelve cases in lesson 11-01 add up to: **QML checks what it can read,
and runs the rest.** A string literal where a number goes is refused at load.
A binding that computes a string where a number goes is not.

## Fix

**Test the values.** This tier has no diagnostic channel, so there is nothing to
hook. The only instrument that catches it is a test that loads the file and
asserts that the width is what the file says it should be.

```cpp
const auto loaded = host.load(url);
RC_REQUIRE(loaded.has_value());
RC_CHECK_NEAR(loaded.value()->property("width").toDouble(), 100.0, 1e-12);
```

**Treat a zero size as a defect worth asserting against.** Most of this tier
lands on zero, so a check that no visible element has zero width or height
catches a lot of it for one line of test.

**Guard the arithmetic, not the assignment.** If a denominator can be zero, the
binding is where to say so, because by the time the property has the value the
information is gone.

**Do not reach for `anchors.fill: parent` in a component that might be created
without one.** `Component.onCompleted` with a check, or a size the component
sets itself, both fail visibly rather than silently.
