## Symptom

A difference is explained, written up, and wrong. The first explanation sounded right.

## Cause

A cause was accepted because it would produce the symptom. The first explanation was scrubbing wheels; but it predicted a short turn from rest too, and changing the friction made no difference. The turns were 1.01, 0.74 and 0.85 of those asked.

Several causes can produce the same symptom. An explanation that fits the symptom is a hypothesis; it becomes a cause only when an experiment that would give a different result for each candidate gives the result it predicts.

## Fix

List the candidates and run an experiment that separates them before writing any of them down.

// vary one thing at a time: friction, time since the drive, whether it had moved at all
