## Symptom

An arm built from a published table is right in its home pose and wrong in others, or wrong by a plausible amount.

## Cause

The table is for one convention and the code reads the other: the same row gave frames 0.170 m apart.

## Fix

Write the convention with every table, and keep one function for each; test the tool position at two or three poses against a measurement or the maker's own.

```cpp
t.convention == kModified ? dh_modified(...) : dh_standard(...);
```
