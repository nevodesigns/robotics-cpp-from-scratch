title: A setting that was never written to the file
match: a setting is in the file when it is saved and not when it is set, and a port that is not a port is refused
match: expected exists_before
platforms: linux, windows
teaches: 12-05-the-setting-from-last-time

## Symptom

The operator changes the robot address, the station is closed by killing it or crashes, and the next run has the old address. Or a test of the save reads back from the same object and passes.

## Cause

`QSettings` keeps changes in memory and writes the file at `sync()` and at destruction. A second object on the same file in the same process sees the memory. Measured: before `save()` the file **did not exist**; after, it held the host, the port **5001**, the limit **2.5** and the version.

## Fix

Save when the operator changes something, and say whether it worked:

```cpp
bool save() { settings_.sync(); return settings_.status() == QSettings::NoError; }
```
