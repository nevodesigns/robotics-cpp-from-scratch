## Symptom

Given a goal it cannot reach, the vehicle drives toward it and stops against a wall. The goal was inside a closed yard, or behind a gate the map did not know about.

## Cause

The search reached its limit and returned the nearest pose it had found as if it were a path to the goal.

A search that runs out of expansions has found the best it can, not a path. Returning the nearest pose as if it were the goal sends the vehicle toward a place it cannot reach.

## Fix

Return found false with an empty path, and let the mission decide. A goal walled in was reported as not found after 4000 expansions, with an empty path.

```cpp
const rc::drive::HybridResult r = rc::drive::hybrid_astar(grid, start, goal, cfg);
if (!r.found) report_unreachable();
```
