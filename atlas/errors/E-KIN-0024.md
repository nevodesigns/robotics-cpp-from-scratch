id: E-KIN-0024
title: Counting a pose as unreachable because one elbow could not hold it
match: a point the arm cannot reach, or no pose can hold, has no manipulability
match: expected this to be true: best_manipulability
platforms: linux, windows
teaches: 13-10-where-the-arm-works-well
---

## Symptom

A map of where the arm can work has holes in it, and the holes move when the code is changed to prefer the other elbow.

## Cause

Every reachable point has two poses, elbow up and elbow down, and a joint limit can rule out one without the other. A map built from
one branch reports the point as unreachable when the other branch holds it.

`best_manipulability` looks at both and keeps the better legal one, and it returns a negative number only when neither is legal. The test checks a
point beyond the links, one inside the hole, an ordinary one, and the elbow square on the x axis, where the determinant is exactly l1 times l2.

## Fix

```cpp
if (both.up_holds)   best = std::max(best, std::fabs(l1 * l2 * std::sin(both.elbow_up.q2)));
if (both.down_holds) best = std::max(best, std::fabs(l1 * l2 * std::sin(both.elbow_down.q2)));
```
