## Symptom

Over several seconds of null space motion the tool drifts away from where it was. The tool creeps a fraction of a millimetre a second during self motion.

## Cause

The projection holds to first order only, so each step moves the tool a little. With no correction the tool drifted 0.00076 m.

The null space is computed at the present pose, and the motion in it is a straight line. The arm moves on a curve, so each step leaves the true null space a little, and the tool moves by that little.

## Fix

Correct the tool's error every step as well as projecting the secondary motion. With a correction the drift was 0.00037 m.

```cpp
const std::vector<double> back = rc::arm::dls_step(j, e_scaled, lambda);   // e_scaled = kp * error * dt
```
