## Symptom

The speed profile dips to a crawl at one point of the path, and the run takes longer for it.

## Cause

The curvature at a corner point of a planned path is very high (8.6 s for the corner path as it was, 8.2 s smoothed).

## Fix

Smooth the path (26-03) before profiling it, or plan with arcs (26-01).

```cpp
const auto v = speed_profile(smooth_path(path, &grid, cfg).path, lim, nullptr);
```
