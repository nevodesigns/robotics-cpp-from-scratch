## Symptom

After calibration the tool goes to the right place, and a fitted link length is not the one a ruler gives. A fitted parameter disagrees with a ruler, though the tool is accurate.

## Cause

Some corrections cannot be told apart: they move the tool the same way whatever the joints do. The offsets along joints 2 and 3, which are parallel, differed by 0.000000000000 m in their effect, so the measurements fix only their sum.

When two parameters move the tool the same way at every pose, the measurements see only their sum. The fit can split the sum between them however it likes, and a split that fits is not the true one.

## Fix

Use the calibrated table for the tool's place only. Drop or fix the dependent corrections before reading values off it, and measure the lengths another way if they matter.

```cpp
// d2 and d3 move the tool together: fit their sum, keep d2 at its drawn value
```
