## Symptom

After smoothing, the path passes much closer to obstacles than the plan did.

## Cause

The shortcut pass was checked with no margin, so it pulled the path tight against the obstacles. The clearance along the path was 0.0001 m, against 0.0202 m with the planner's margin kept.

## Fix

Use the planning margin in every pass that moves the path: shortcut, corner cutting and any later edit.

```cpp
path = rc::arm::shortcut(problem, path, n, seed, problem.margin);   // not 0.0
```
