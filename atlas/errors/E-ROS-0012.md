id: E-ROS-0012
title: A convenience node that stops the robot, or a node restarted without being silent
match: an optional node that stalls and cannot be restarted is given up on without stopping the graph
match: a restart of a node that works gives it a fresh deadline, so it is not reported again at once, and a node that is never silent is never restarted
platforms: linux, windows
teaches: 17-20-a-graph-that-looks-after-itself
---

## Symptom

The robot stops because a viewer's window failed to open, or a healthy node is restarted every few seconds for no reason.

## Cause

A give up on an optional node does not make the graph untrustworthy: the viewer was given up on once, gave_up() stayed false and the arm got 49 move commands in 5 s with no stops. A restart gives the node a fresh deadline: one stall in 6 s gave 1 stalled event, 1 restart of the sensor and 0 of the viewer.

## Fix

Mark what is not worth stopping for as optional, and re-arm the deadline on a restart.

```cpp
w.monitor.on_message(now);
```
