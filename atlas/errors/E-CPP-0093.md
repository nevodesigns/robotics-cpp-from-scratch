## Symptom

A function that takes a `Controller` gets a `Proportional` and behaves as if it were the do-nothing base. The same function taking a reference works.

## Cause

A by-value parameter is a new object of exactly the declared type, copy-constructed from the argument. Only the base part of the derived object is copied: the derived part, and the behaviour that went with it, is sliced off.

Measured: gain 3, error 2: by reference **6**, by value **0**. (A base class with a pure virtual function cannot be passed by value at all, which turns this into a compile error.)

## Fix

Take a polymorphic type by reference or by pointer:

```cpp
double run(const Controller& c, double error);
```
