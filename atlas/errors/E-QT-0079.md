## Symptom

A wait for a component never returns, because the code waits for Ready and the component went to Error, or it returns and the next line uses a null object with no explanation.

## Cause

The status leaves Loading for Ready or for Error, and a wait that quits only on Ready never quits on the second. Measured: a file with a syntax error became **Error** and the reason was `.../main.qml:2:15: Expected token`; a file that did not exist was an Error after **0** ms.

## Fix

Quit on any status that is not Loading, and report the errors:

```cpp
if (status != QQmlComponent::Loading) loop.quit();
```
