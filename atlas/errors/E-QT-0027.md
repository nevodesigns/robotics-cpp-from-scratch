## Symptom

A name field limited to ten letters accepts five emoji and a half, or a frame of declared length 8 holds 11 bytes of text. A truncation cuts a character in half and leaves a replacement character where a letter was.

## Cause

Three different things are called length. A byte string counts bytes, `QString::length()` counts the 16 bit units it stores, and a person counts letters. For plain ASCII they agree, and for anything else they do not.

Measured:

| text | bytes in UTF-8 | `length()` | letters |
|---|---|---|---|
| abc | 3 | 3 | 3 |
| micro sign | 2 | 1 | 1 |
| smiling emoji | 4 | 2 | 1 |

## Fix

Say which you mean, and count code points by converting to UCS-4:

```cpp
inline int letters_in(const QString& text) { return static_cast<int>(text.toUcs4().size()); }
```

A limit that protects a wire format is a limit in bytes; one that protects a screen is a limit in letters.
