title: A file from an older version read as defaults
match: a file of the first version is brought to the second once, in the units of the second, and its old names are gone
match: expected again.limit_mps
platforms: linux, windows

## Symptom

After an upgrade the station starts at its default address and its default speed, and the operator thinks the settings were lost. Or a migration runs at every start and divides the speed by a thousand each time.

## Cause

A new version reads the names it knows. A file of an old one has other names, and sometimes other units. Measured: a version 1 file with `robot_ip` and `speed_limit_mm=1500` became host **192.168.1.20** and **1.5** m/s, with the old names gone; starting again left **1.5**, because the version was now 2.

## Fix

Migrate in a function that tests the version, converts, removes the old names and writes the new version:

```cpp
if (version() >= kVersion) return;
// ... convert ...
settings_.setValue("version", kVersion);
```
