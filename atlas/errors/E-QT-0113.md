## Symptom

A test of the command line never reports: the test run ends in the middle with the usage text on the screen. Or `--help` starts the whole station.

## Cause

`QCommandLineParser::process` prints the error or the help and calls `exit`, which is right in `main` and ends a test. `parse` returns. Measured: `--help` and `--version` were good lines that set a flag, a refused line left the result as it was, and a null result or message was allowed.

## Fix

Use parse(), and return the answer:

```cpp
if (!parser.parse(args)) { *err = parser.errorText(); return false; }
```
