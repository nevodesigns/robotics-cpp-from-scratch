## Symptom

The arm takes a roundabout route between nearby poses, and spends time and torque on it. The arm wanders through poses nobody would choose.

## Cause

The path was used as the planner found it. A sampling planner's path is a random walk through the free space; the raw one here was 4.83 times the straight line in joint space.

A sampling planner's path joins random nodes, so it zig-zags through the free space. Nothing in the planner asks for the path to be short, only free.

## Fix

Run a shortcut pass after every plan: pick two points, join them if the straight line between them is free, repeat. After 150 shortcuts the path was 1.85 times the straight line.

```cpp
path = rc::arm::shortcut(problem, path, 150, seed, problem.margin);
```
