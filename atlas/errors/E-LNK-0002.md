## Symptom

The linker reports that a function or variable is defined more than once, naming
two object files.

## Cause

A function body was placed in a header, and more than one source file included
that header. Each one produced its own definition, and the rule is that there
must be exactly one.

## Fix

Move the body into a single .cpp file and leave only the declaration in the
header. If the function must stay in the header, mark it inline, which tells the
linker that identical copies are expected and to keep one. Functions defined
inside a class body are implicitly inline already.
