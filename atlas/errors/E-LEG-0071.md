## Symptom

A loop that is stable on the bench rings once the robot is assembled, or after the bus is loaded with more servos.

## Cause

The delay of the real loop was never measured, so the margin was never known. The lesson found the largest delay each set of gains could stand: 19 ms for the stiff ones and 43 ms for the gentle ones, more than twice the margin for a joint that is only somewhat slower. A bus that adds a few milliseconds (29-07 measured 2.98 ms for six servos at 1 Mbit/s, 14.3 ms at 115 200 bit/s) can use up a small margin.

## Fix

Measure the delay on the real bus and compare it with the margin the gains have.

```cpp
const double margin = rc::legged::max_stable_delay(j, 0.5, 2.0, 0.001, 0.2);   // 0.019 s stiff, 0.043 s gentle
if (measured_delay > 0.5 * margin) choose_gentler_gains();
```

The margin is a number for every loop, like its gains, and it should be written down next to them.
