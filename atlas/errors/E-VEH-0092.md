## Symptom

Following with Stanley, the steering jumps at each kink of the path.

## Cause

Stanley follows the path at the front axle with no lookahead, so its heading error is a step wherever the path has a corner. On a smooth bend it hugs the path closely, 0.036 m at most off it.

## Fix

Smooth the path first (26-03), or use pure pursuit where the path has kinks.

```cpp
rc::drive::FollowConfig cfg;
cfg.method = rc::drive::kStanley;   // on a smoothed path
```
