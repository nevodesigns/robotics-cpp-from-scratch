## Symptom

A cloned policy that drifts is given many more demonstrations, and it still fails in the same places.

## Cause

The new demonstrations were the expert's own runs, and they go where the expert goes. The clone's failures happen in the states its own mistakes lead to, which a good expert seldom visits, so the new data adds little where it is needed.

## Fix

Collect on the learner's path: let the learner drive and record, at each state it reaches, the expert's action as the label.

```cpp
const auto extra = rc::learn::collect_on_learner(task, policy, 0.6, 0.8, 20, 100, 1000, seed);
data.insert(data.end(), extra.begin(), extra.end());
```

Noise in the expert's executed action (38-01) widens the data a little; it is not a substitute.
