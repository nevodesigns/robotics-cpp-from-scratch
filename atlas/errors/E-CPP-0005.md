title: Missing semicolon after a struct or class definition

## Symptom

A struct or class definition produces an error on the line after its closing
brace, often about an unexpected token or a missing identifier.

## Cause

A class or struct definition is a statement, so it ends with a semicolon after
the closing brace. This is different from a function definition, which does not.
The inconsistency is a genuine wart in the language and it catches everyone.

## Fix

End every class and struct definition with the closing brace followed by a
semicolon.
