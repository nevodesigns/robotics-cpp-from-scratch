## Symptom

The planner is slow, and slower the finer the headings. The headings were made finer to get a better path.

## Cause

Each cell holds a node for every heading bin, so the search space grows with the bins. With 12 headings the search took 1146 expansions; with 48 it took 2675.

Hybrid A* keeps one node per cell and heading bin, so the space it searches grows with the number of bins. Finer headings give smoother paths and cost search time.

## Fix

Use the fewest headings that let the car reach the goal heading within its tolerance, and cap the expansions so a hard query ends.

```cpp
rc::drive::HybridConfig cfg;
cfg.theta_bins = 24;
cfg.max_expansions = 30000;
```
