title: One frame for three arms
match: only the first arm of the delta reached the point
match: the delta's angles were right for one arm and wrong for the others
match: the three arms are symmetric: a point on the axis gives equal angles, and the reach is a dome
platforms: linux, windows

## Symptom

The delta's first arm goes to the right angle and the other two put the platform somewhere else, or the solver refuses a point in the middle of the work.

## Cause

The same solution was used for all three arms in one frame. The arms are 120 degrees apart, and the closed form for one arm assumes the target is given in that arm's own frame.

## Fix

Turn the target into the frame of arm k, by 120 degrees times k, before solving it, and solve each arm on its own (the platform does not tilt, so they do not interact). The forward kinematics put the platform back at each of the 386 reachable grid points to 0.000000000 m.

```cpp
for (int k = 0; k < 3; ++k) {
  const double xk = x * cs[k] + y * sn[k];
  const double yk = -x * sn[k] + y * cs[k];
  if (!rc::arm::delta_arm_angle(robot, xk, yk, z, th[k])) return false;
}
```

rc::arm::delta_ik does the three turns for you; test it against delta_fk.
