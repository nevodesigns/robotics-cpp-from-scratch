## Symptom

A run is logged, and replaying the log does not give the same result. The difference is tiny at first and grows. Or two values that were different when written are equal when read, so a test that compares them says they match.

## Cause

`std::cout << x` writes six significant digits. A double has about sixteen, and up to seventeen are needed to tell it from its neighbour, so the text is not the number.

Measured, 20000 readings of mixed size written as text and read back to see whether they are exactly the same: **0** through a stream with six digits, **5627** through `std::to_string` (the large ones, which it writes in full), and **20000** through `shortest_text`. The sum `0.1 + 0.2` and the number `0.3` are different doubles, and six digits write both as "0.3".

## Fix

Write the fewest digits that read back as the same double:

```cpp
for (int digits = 1; digits <= 17; ++digits) {
  std::ostringstream out;
  out << std::setprecision(digits) << value;
  if (std::strtod(out.str().c_str(), nullptr) == value) { text = out.str(); break; }
}
```
